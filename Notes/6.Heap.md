## 📖 Chapter 1: Foundations & Definitions

### 1.1 What is a Heap?

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                           FORMAL DEFINITION                               ║
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  A HEAP is a specialized tree-based data structure that satisfies        ║
║  the HEAP PROPERTY:                                                       ║
║                                                                           ║
║  • MAX-HEAP: For every node i other than the root,                       ║
║              A[Parent(i)] ≥ A[i]                                          ║
║              (Parent is always greater than or equal to children)         ║
║                                                                           ║
║  • MIN-HEAP: For every node i other than the root,                       ║
║              A[Parent(i)] ≤ A[i]                                          ║
║              (Parent is always less than or equal to children)            ║
║                                                                           ║
║  Additionally, a heap must be a COMPLETE BINARY TREE.                     ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

### 1.2 Complete Binary Tree Property

A **Complete Binary Tree** is a binary tree in which:
01. All levels except possibly the last are completely filled
02. All nodes in the last level are as far LEFT as possible

```
COMPLETE BINARY TREES:

    ✓ VALID                    ✓ VALID                   ✓ VALID
    
        10                        10                         10
       /  \                      /  \                       /  \
      20   30                   20   30                    20   30
     /  \                      /  \  /                    /
    40   50                   40  50 60                  40

NOT COMPLETE (INVALID FOR HEAP):

    ✗ INVALID                  ✗ INVALID                 ✗ INVALID
    
        10                        10                         10
       /  \                      /  \                       /  \
      20   30                   20   30                    20   30
        \                      /       \                       /  \
         50                   40        60                    40   50
    (Gap on left)         (Gap in middle)              (Missing level 2 node)
```

### 1.3 Why Complete Binary Tree Matters

```
╔═══════════════════════════════════════════════════════════════════════════╗
║  THEOREM: A complete binary tree with n nodes has height h = ⌊log₂n⌋      ║
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  PROOF:                                                                   ║
║  • A complete binary tree of height h has:                                ║
║    - Minimum nodes: 2^h (only root at last level)                        ║
║    - Maximum nodes: 2^(h+1) - 1 (last level full)                        ║
║                                                                           ║
║  • For n nodes: 2^h ≤ n ≤ 2^(h+1) - 1                                    ║
║  • Taking log₂:  h ≤ log₂n < h + 1                                       ║
║  • Therefore:    h = ⌊log₂n⌋                                              ║
║                                                                           ║
║  IMPLICATION: All heap operations involving tree height are O(log n)     ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

```
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  For 0-BASED INDEXING (most common in programming):                       ║

║  ─────────────────────────────────────────────                            ║
║  • Parent(i)      = ⌊i / 2⌋                                               ║

║  • Right Child(i) = 2i + 1                                                ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

## 📖 Chapter 3: Heap Properties & Theorems

### 3.1 Structural Properties

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                    IMPORTANT HEAP PROPERTIES                              ║
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  PROPERTY 1: Height                                                       ║
║  ─────────────────                                                        ║
║  A heap with n elements has height h = ⌊log₂n⌋                           ║
║                                                                           ║
║  PROPERTY 2: Number of Nodes at Each Level                                ║
║  ──────────────────────────────────────────                               ║
║  Level k has at most 2^k nodes                                            ║
║  Level 0 (root): 1 node                                                   ║
║  Level 1: 2 nodes                                                         ║
║  Level 2: 4 nodes                                                         ║
║  Level h: 1 to 2^h nodes                                                  ║
║                                                                           ║
║  PROPERTY 3: Leaf Nodes                                                   ║
║  ─────────────────────                                                    ║
║  In a heap of n elements, leaves are at indices ⌊n/2⌋ to n-1             ║
║  (approximately half the nodes are leaves!)                               ║
║                                                                           ║
║  PROPERTY 4: Root Property                                                ║
║  ─────────────────────────                                                ║
║  • In MAX-HEAP: Root contains the MAXIMUM element                         ║
║  • In MIN-HEAP: Root contains the MINIMUM element                         ║
║                                                                           ║
║  PROPERTY 5: Subtree Property                                             ║
║  ────────────────────────────                                             ║
║  Every subtree of a heap is also a heap                                   ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

### 3.2 Heap vs BST - Critical Differences

```
╔════════════════════════════════════════════════════════════════════════════╗
║           HEAP                    vs              BST                      ║
╠════════════════════════════════════════════════════════════════════════════╣
║                                                                            ║
║  Ordering: Vertical only              Ordering: Horizontal + Vertical      ║
║  (parent vs children)                 (left < parent < right)              ║
║                                                                            ║
║       MAX-HEAP:                              BST:                          ║
║          90                                   50                           ║
║         /  \                                 /  \                          ║
║        80   70                              30   70                        ║
║       / \                                  / \   / \                       ║
║      50  60                               20 40 60  80                     ║
║                                                                            ║
║  No left-right order!              Left < Node < Right always!             ║
║  (80 and 70 are siblings,          (In-order traversal gives              ║
║   no relationship required)         sorted sequence)                       ║
║                                                                            ║
║  Shape: Always complete              Shape: Can be any shape               ║
║         binary tree                         (might be skewed)              ║
║                                                                            ║
║  Best for: Priority Queue            Best for: Searching, Sorting          ║
║           (need max/min quickly)            (need all data ordered)        ║
║                                                                            ║
╚════════════════════════════════════════════════════════════════════════════╝
```

### 3.3 Important Theorems

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                          THEOREM 1                                        ║
╠═══════════════════════════════════════════════════════════════════════════╣
║  In a max-heap, the maximum element is always at the root (index 0).      ║
║                                                                           ║
║  PROOF:                                                                   ║
║  By contradiction. Assume max element M is not at root.                   ║
║  Then M is at some node i where i > 0.                                    ║
║  By heap property, Parent(i) ≥ M.                                         ║
║  But M is maximum, so Parent(i) cannot be > M.                            ║
║  Therefore Parent(i) = M.                                                 ║
║  Continuing this argument up to root, root must contain M.                ║
║  Contradiction! Hence, max must be at root. ∎                             ║
╚═══════════════════════════════════════════════════════════════════════════╝

╔═══════════════════════════════════════════════════════════════════════════╗
║                          THEOREM 2                                        ║
╠═══════════════════════════════════════════════════════════════════════════╣
║  A heap with n nodes has exactly ⌈n/2⌉ leaves.                           ║
║                                                                           ║
║  PROOF:                                                                   ║
║  In a complete binary tree stored in array [0...n-1]:                     ║
║  • Last internal node has index ⌊(n-1-1)/2⌋ = ⌊n/2⌋ - 1                 ║
║  • So internal nodes are at indices 0 to ⌊n/2⌋ - 1                       ║
║  • Number of internal nodes = ⌊n/2⌋                                       ║
║  • Number of leaves = n - ⌊n/2⌋ = ⌈n/2⌉ ∎                               ║
╚═══════════════════════════════════════════════════════════════════════════╝

╔═══════════════════════════════════════════════════════════════════════════╗
║                          THEOREM 3                                        ║
╠═══════════════════════════════════════════════════════════════════════════╣
║  Building a heap from n elements can be done in O(n) time.                ║
║                                                                           ║
║  PROOF SKETCH:                                                            ║
║  Using "heapify-down" from bottom up:                                     ║
║  • Leaves (⌈n/2⌉ nodes): 0 swaps each                                    ║
║  • Level h-1 (n/4 nodes): at most 1 swap each                            ║
║  • Level h-2 (n/8 nodes): at most 2 swaps each                           ║
║  • ...                                                                    ║
║  • Level 0 (1 node): at most h swaps                                      ║
║                                                                           ║
║  Total work = Σ(k=0 to h) (n/2^(k+1)) * k                                ║
║             = n * Σ(k=0 to h) k/2^(k+1)                                   ║
║             ≤ n * 2 = O(n) ∎                                              ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

## 📖 Chapter 4: Core Operations - Detailed Algorithms

### 4.1 HEAPIFY (Bubble Down / Sift Down)

The most fundamental operation - restores heap property for a subtree.

```
╔═══════════════════════════════════════════════════════════════════════════╗
║  HEAPIFY (MAX-HEAPIFY) - Also called: Bubble Down, Sift Down, Percolate  ║
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  PURPOSE: Given a node where the subtrees are heaps but the node         ║
║           itself might violate heap property, fix it.                     ║
║                                                                           ║
║  PRECONDITION: Left and right subtrees are already valid heaps           ║
║  POSTCONDITION: Subtree rooted at given node is a valid heap             ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

**Algorithm Visualization:**

```
MAX-HEAPIFY(A, i) - Fix heap property at node i

EXAMPLE: Heapify at index 0 (value 10)
         Subtrees ARE valid heaps, but root violates property

INITIAL STATE:
                    ┌────┐
         Index 0 →  │ 10 │  ← PROBLEM! Smaller than children
                    └────┘
                   /       \
            ┌────┐          ┌────┐
 Index 1 → │ 80 │          │ 70 │ ← Index 2
            └────┘          └────┘
           /      \         /
      ┌────┐   ┌────┐   ┌────┐
      │ 50 │   │ 40 │   │ 60 │
      └────┘   └────┘   └────┘

STEP 1: Compare node with its children
        - Left child (80) at index 1
        - Right child (70) at index 2
        - Largest among {10, 80, 70} = 80 at index 1

STEP 2: Since largest ≠ current node, SWAP
        Swap A[0] with A[1]

                    ┌────┐
         Index 0 →  │ 80 │  ← Swapped up
                    └────┘
                   /       \
            ┌────┐          ┌────┐
 Index 1 → │ 10 │          │ 70 │ ← Index 2
            └────┘          └────┘
           /      \         /
      ┌────┐   ┌────┐   ┌────┐
      │ 50 │   │ 40 │   │ 60 │
      └────┘   └────┘   └────┘

STEP 3: Recursively heapify at index 1
        - Left child (50) at index 3
        - Right child (40) at index 4
        - Largest among {10, 50, 40} = 50 at index 3
        - Swap A[1] with A[3]

                    ┌────┐
         Index 0 →  │ 80 │
                    └────┘
                   /       \
            ┌────┐          ┌────┐
 Index 1 → │ 50 │          │ 70 │
            └────┘          └────┘
           /      \         /
      ┌────┐   ┌────┐   ┌────┐
      │ 10 │   │ 40 │   │ 60 │
      └────┘   └────┘   └────┘

STEP 4: Recursively heapify at index 3
        - Index 3 has no children (it's a leaf)
        - DONE!

FINAL RESULT: Valid Max-Heap ✓
```

**Pseudocode:**

```
MAX-HEAPIFY(A, n, i)
─────────────────────────────────────────────
Input: Array A, heap size n, index i to heapify
Output: Subtree rooted at i satisfies heap property

01.  largest ← i
02.  left ← 2*i + 1
03.  right ← 2*i + 2

04.  // Check if left child exists and is larger
05.  if left < n AND A[left] > A[largest] then
06.      largest ← left

07.  // Check if right child exists and is larger
08.  if right < n AND A[right] > A[largest] then
09.      largest ← right

10. // If largest is not the current node, swap and recurse
11. if largest ≠ i then
12.     SWAP(A[i], A[largest])
13.     MAX-HEAPIFY(A, n, largest)  // Recursive call
─────────────────────────────────────────────

TIME COMPLEXITY: O(log n) - traverses at most the height of tree
SPACE COMPLEXITY: O(log n) for recursive call stack
                  O(1) if implemented iteratively
```

### 4.2 BUILD-HEAP

Convert an arbitrary array into a heap.

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                         BUILD-HEAP ALGORITHM                              ║
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  KEY INSIGHT: Leaves are already valid heaps (single nodes)!              ║
║               Start from last internal node and work backwards.           ║
║                                                                           ║
║  WHY BOTTOM-UP?                                                           ║
║  When we heapify node i, both children subtrees are already heaps         ║
║  (because we processed them first). This satisfies heapify's              ║
║  precondition!                                                            ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

**Visualization:**

```
BUILD-MAX-HEAP from array [4, 10, 3, 5, 1, 8, 7]

INITIAL ARRAY (visualized as tree):

                    ┌────┐
                    │  4 │  Index 0
                    └────┘
                   /       \
            ┌────┐          ┌────┐
            │ 10 │          │  3 │  Index 1, 2
            └────┘          └────┘
           /      \         /      \
      ┌────┐   ┌────┐   ┌────┐   ┌────┐
      │  5 │   │  1 │   │  8 │   │  7 │  Index 3, 4, 5, 6
      └────┘   └────┘   └────┘   └────┘

n = 7, so last internal node = ⌊7/2⌋ - 1 = 2

STEP 1: Heapify index 2 (value 3)
        Children: 8, 7
        Largest = 8 → Swap 3 and 8

                    ┌────┐
                    │  4 │
                    └────┘
                   /       \
            ┌────┐          ┌────┐
            │ 10 │          │  8 │  ← Changed
            └────┘          └────┘
           /      \         /      \
      ┌────┐   ┌────┐   ┌────┐   ┌────┐
      │  5 │   │  1 │   │  3 │   │  7 │
      └────┘   └────┘   └────┘   └────┘
                        ↑ Changed

STEP 2: Heapify index 1 (value 10)
        Children: 5, 1
        Largest = 10 (itself) → No swap needed ✓

STEP 3: Heapify index 0 (value 4)
        Children: 10, 8
        Largest = 10 → Swap 4 and 10

                    ┌────┐
                    │ 10 │  ← Changed
                    └────┘
                   /       \
            ┌────┐          ┌────┐
            │  4 │          │  8 │
            └────┘          └────┘  ← Changed

        Now recursively heapify index 1 (value 4)
        Children: 5, 1
        Largest = 5 → Swap 4 and 5

                    ┌────┐
                    │ 10 │
                    └────┘
                   /       \
            ┌────┐          ┌────┐
            │  5 │          │  8 │
            └────┘          └────┘
           /      \         /      \
      ┌────┐   ┌────┐   ┌────┐   ┌────┐
      │  4 │   │  1 │   │  3 │   │  7 │
      └────┘   └────┘   └────┘   └────┘

FINAL MAX-HEAP: [10, 5, 8, 4, 1, 3, 7] ✓
```

**Pseudocode:**

```
BUILD-MAX-HEAP(A)
─────────────────────────────────────────────
Input: Array A of n elements
Output: Array A rearranged as a max-heap

01.  n ← length(A)
02.  // Start from last internal node
03.  for i ← ⌊n/2⌋ - 1 down to 0 do
04.      MAX-HEAPIFY(A, n, i)
─────────────────────────────────────────────

TIME COMPLEXITY: O(n) - NOT O(n log n)!
                 (See proof in Chapter 3.3)
```

### 4.3 INSERT (Push)

Add a new element to the heap.

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                            INSERT ALGORITHM                               ║
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  STRATEGY: "Bubble Up" / "Sift Up" / "Swim"                              ║
║                                                                           ║
║  1. Add new element at the END (maintains complete tree property)         ║
║  2. Compare with parent; if heap property violated, swap                  ║
║  3. Repeat until heap property satisfied or reach root                    ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

**Visualization:**

```
INSERT 85 into heap [80, 70, 60, 50, 40, 30, 20]

INITIAL MAX-HEAP:
                    ┌────┐
                    │ 80 │
                    └────┘
                   /       \
            ┌────┐          ┌────┐
            │ 70 │          │ 60 │
            └────┘          └────┘
           /      \         /      \
      ┌────┐   ┌────┐   ┌────┐   ┌────┐
      │ 50 │   │ 40 │   │ 30 │   │ 20 │
      └────┘   └────┘   └────┘   └────┘

STEP 1: Add 85 at the end (index 7)

                    ┌────┐
                    │ 80 │
                    └────┘
                   /       \
            ┌────┐          ┌────┐
            │ 70 │          │ 60 │
            └────┘          └────┘
           /      \         /      \
      ┌────┐   ┌────┐   ┌────┐   ┌────┐
      │ 50 │   │ 40 │   │ 30 │   │ 20 │
      └────┘   └────┘   └────┘   └────┘
     /
┌────┐
│ 85 │ ← NEW (index 7)
└────┘

STEP 2: Compare with parent (50 at index 3)
        85 > 50? YES → SWAP

                    ┌────┐
                    │ 80 │
                    └────┘
                   /       \
            ┌────┐          ┌────┐
            │ 70 │          │ 60 │
            └────┘          └────┘
           /      \         /      \
      ┌────┐   ┌────┐   ┌────┐   ┌────┐
      │ 85 │   │ 40 │   │ 30 │   │ 20 │ ← 85 moved up
      └────┘   └────┘   └────┘   └────┘
     /
┌────┐
│ 50 │ ← 50 moved down
└────┘

STEP 3: Compare with parent (70 at index 1)
        85 > 70? YES → SWAP

                    ┌────┐
                    │ 80 │
                    └────┘
                   /       \
            ┌────┐          ┌────┐
            │ 85 │          │ 60 │  ← 85 moved up
            └────┘          └────┘
           /      \         /      \
      ┌────┐   ┌────┐   ┌────┐   ┌────┐
      │ 70 │   │ 40 │   │ 30 │   │ 20 │ ← 70 moved down
      └────┘   └────┘   └────┘   └────┘
     /
┌────┐
│ 50 │
└────┘

STEP 4: Compare with parent (80 at index 0)
        85 > 80? YES → SWAP

                    ┌────┐
                    │ 85 │  ← NEW ROOT!
                    └────┘
                   /       \
            ┌────┐          ┌────┐
            │ 80 │          │ 60 │  ← 80 moved down
            └────┘          └────┘
           /      \         /      \
      ┌────┐   ┌────┐   ┌────┐   ┌────┐
      │ 70 │   │ 40 │   │ 30 │   │ 20 │
      └────┘   └────┘   └────┘   └────┘
     /
┌────┐
│ 50 │
└────┘

STEP 5: No more parents (reached root)
        DONE!

FINAL: [85, 80, 60, 70, 40, 30, 20, 50]
```

**Pseudocode:**

```
HEAP-INSERT(A, key)
─────────────────────────────────────────────
Input: Heap array A, new element key
Output: A with key inserted, maintaining heap property

01.  A.append(key)           // Add at end
02.  i ← length(A) - 1       // Index of new element
03.  
04.  // Bubble up
05.  while i > 0 do
06.      parent ← ⌊(i - 1) / 2⌋
07.      if A[parent] >= A[i] then
08.          break           // Heap property satisfied
09.      SWAP(A[parent], A[i])
10.     i ← parent          // Move up
─────────────────────────────────────────────

TIME COMPLEXITY: O(log n) - at most height swaps
SPACE COMPLEXITY: O(1)
```

### 4.4 EXTRACT-MAX (Pop)

Remove and return the maximum element.

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                         EXTRACT-MAX ALGORITHM                             ║
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  STRATEGY:                                                                ║
║  1. Save the root (maximum element)                                       ║
║  2. Replace root with LAST element (maintains complete tree)              ║
║  3. Remove last position                                                  ║
║  4. "Bubble Down" the new root to restore heap property                   ║
║                                                                           ║
║  WHY USE LAST ELEMENT?                                                    ║
║  - Removing from middle would break complete tree property                ║
║  - Last element removal is O(1)                                           ║
║  - We only need to fix ONE path (root to leaf)                           ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

**Visualization:**

**Pseudocode:**

```
HEAP-EXTRACT-MAX(A)
─────────────────────────────────────────────
Input: Heap array A
Output: Maximum element (removed from heap)

01.  if length(A) == 0 then
02.      error "Heap underflow"
03.  
04.  max ← A[0]              // Save maximum
05.  A[0] ← A[length(A) - 1] // Move last to root
06.  A.removeLast()          // Shrink array
07.  
08.  if length(A) > 0 then
09.      MAX-HEAPIFY(A, length(A), 0)  // Bubble down
10. 
11. return max
─────────────────────────────────────────────

TIME COMPLEXITY: O(log n) - heapify from root
SPACE COMPLEXITY: O(1) if iterative heapify, O(log n) if recursive
```

### 4.6 INCREASE-KEY / DECREASE-KEY

Change priority of an existing element.

```
HEAP-INCREASE-KEY(A, i, newKey)  // For Max-Heap
─────────────────────────────────────────────
Input: Heap A, index i, new larger key
Precondition: newKey >= A[i]

01.  if newKey < A[i] then
02.      error "New key smaller than current"
03.  
04.  A[i] ← newKey
05.  
06.  // Bubble up (new key might be larger than parent)
07.  while i > 0 AND A[parent(i)] < A[i] do
08.      SWAP(A[i], A[parent(i)])
09.      i ← parent(i)
─────────────────────────────────────────────

TIME COMPLEXITY: O(log n)

HEAP-DECREASE-KEY(A, i, newKey)  // For Max-Heap
─────────────────────────────────────────────
Input: Heap A, index i, new smaller key
Precondition: newKey <= A[i]

01.  A[i] ← newKey
02.  MAX-HEAPIFY(A, length(A), i)  // Bubble down
─────────────────────────────────────────────

TIME COMPLEXITY: O(log n)
```

### 4.7 DELETE (Delete Arbitrary Element)

```
HEAP-DELETE(A, i)
─────────────────────────────────────────────
Input: Heap A, index i of element to delete

01.  // Replace with last element
02.  A[i] ← A[length(A) - 1]
03.  A.removeLast()
04.  
05.  if i < length(A) then
06.      // Might need to bubble up OR down
07.      if i > 0 AND A[i] > A[parent(i)] then
08.          BUBBLE-UP(A, i)
09.      else
10.         MAX-HEAPIFY(A, length(A), i)
─────────────────────────────────────────────

TIME COMPLEXITY: O(log n)
```

### 5.2 Why Build Heap is O(n), not O(n log n)

```
╔═══════════════════════════════════════════════════════════════════════════╗
║              DETAILED PROOF: BUILD-HEAP is O(n)                           ║
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  Intuition: Most nodes are near the bottom and do little work!            ║
║                                                                           ║
║  For a heap of height h (where h = log n):                                ║
║                                                                           ║
║  Level 0 (root):      1 node,         may do h swaps                     ║
║  Level 1:             2 nodes,        may do h-1 swaps each              ║
║  Level 2:             4 nodes,        may do h-2 swaps each              ║
║  ...                                                                      ║
║  Level h-1:           2^(h-1) nodes,  may do 1 swap each                 ║
║  Level h (leaves):    2^h nodes,      0 swaps (they're leaves!)          ║
║                                                                           ║
║  Total work = Σ(i=0 to h-1) 2^i × (h-i)                                  ║
║                                                                           ║
║  Let k = h - i (substitution):                                            ║
║  Total work = Σ(k=1 to h) 2^(h-k) × k                                    ║
║             = 2^h × Σ(k=1 to h) k/2^k                                    ║
║                                                                           ║
║  The sum Σ(k=1 to ∞) k/2^k converges to 2                                ║
║                                                                           ║
║  So Total work ≤ 2^h × 2 = 2^(h+1) ≈ 2n = O(n)                          ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

**Visual Proof:**

```

Level 0:     ○                    1 node  × 3 max swaps = 3
            / \
Level 1:   ○   ○                  2 nodes × 2 max swaps = 4
          /\   /\
Level 2: ○ ○  ○  ○                4 nodes × 1 max swap  = 4
        /\/\ /\/\ /\
Level 3:○○○○○○○○                  8 nodes × 0 swaps     = 0
                                                        ────
                                            Total:       11

Compare to naive O(n log n):
15 nodes × log(15) ≈ 15 × 4 = 60 operations

Actual: 11 << 60!

Key insight: HALF the nodes are leaves doing ZERO work!
```

## 📖 Chapter 6: Heap Sort Algorithm

### 6.1 The Algorithm

```
╔═══════════════════════════════════════════════════════════════════════════╗
║                          HEAP SORT ALGORITHM                              ║
╠═══════════════════════════════════════════════════════════════════════════╣
║                                                                           ║
║  IDEA:                                                                    ║
║  1. Build a max-heap from the input array                                 ║
║  2. The largest element is at the root                                    ║
║  3. Swap root with last element, reduce heap size by 1                    ║
║  4. Heapify the root                                                      ║
║  5. Repeat until heap size is 1                                           ║
║                                                                           ║
║  PROPERTIES:                                                              ║
║  • Time: O(n log n) - guaranteed for all cases!                          ║
║  • Space: O(1) - in-place sorting                                        ║
║  • Not stable (relative order of equal elements may change)               ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝
```

### 6.2 Step-by-Step Visualization

```

                    └────┘
                   /       \

           /      \
      ┌────┐   ┌────┐
      │  4 │   │  1 │
      └────┘   └────┘

─────────────────────────────────

• Swap root (10) with last (1)
• Reduce heap size to 4

                    ┌────┐

                    └────┘

      ┌────┐
```

### 6.3 Pseudocode

```
HEAP-SORT(A)
─────────────────────────────────────────────
Input: Array A of n elements
Output: Array A sorted in ascending order

01.  BUILD-MAX-HEAP(A)           // O(n)
02.  
03.  for i ← n-1 down to 1 do    // n-1 iterations
04.      SWAP(A[0], A[i])        // Move max to end
05.      MAX-HEAPIFY(A, i, 0)    // Heapify reduced heap
─────────────────────────────────────────────

TIME ANALYSIS:
• Build heap: O(n)
• Loop: (n-1) iterations × O(log n) heapify = O(n log n)
• Total: O(n) + O(n log n) = O(n log n)

SPACE: O(1) - only constant extra space for swaps
```


## 📖 Chapter 9: Complete JavaScript Implementation

```javascript
// ══════════════════════════════════════════════════════════════════════════
//                    COMPLETE HEAP IMPLEMENTATION
// ══════════════════════════════════════════════════════════════════════════

class MaxHeap {
    constructor() {
        this.heap = [];
    }

    // ─────────────────────────────────────────────────────────────────────
    //                         UTILITY METHODS
    // ─────────────────────────────────────────────────────────────────────

    getParentIndex(index) {
        return Math.floor((index - 1) / 2);
    }

    getLeftChildIndex(index) {
        return 2 * index + 1;
    }

    getRightChildIndex(index) {
        return 2 * index + 2;
    }

    hasParent(index) {
        return this.getParentIndex(index) >= 0;
    }

    hasLeftChild(index) {
        return this.getLeftChildIndex(index) < this.heap.length;
    }

    hasRightChild(index) {
        return this.getRightChildIndex(index) < this.heap.length;
    }

    parent(index) {
        return this.heap[this.getParentIndex(index)];
    }

    leftChild(index) {
        return this.heap[this.getLeftChildIndex(index)];
    }

    rightChild(index) {
        return this.heap[this.getRightChildIndex(index)];
    }

    swap(index1, index2) {
        [this.heap[index1], this.heap[index2]] = [this.heap[index2], this.heap[index1]];
    }

    size() {
        return this.heap.length;
    }

    isEmpty() {
        return this.heap.length === 0;
    }

    // ─────────────────────────────────────────────────────────────────────
    //                    CORE OPERATIONS
    // ─────────────────────────────────────────────────────────────────────

    /**
     * PEEK - View maximum element without removing
     * Time Complexity: O(1)
     */
    peek() {
        if (this.isEmpty()) {
            throw new Error("Heap is empty");
        }
        return this.heap[0];
    }

    /**
     * INSERT - Add new element to heap
     * Time Complexity: O(log n)
     */
    insert(value) {
        // Step 1: Add to end of array
        this.heap.push(value);

        // Step 2: Bubble up to maintain heap property
        this.bubbleUp(this.heap.length - 1);

        return this;
    }

    /**
     * BUBBLE UP - Move element up until heap property satisfied
     * Used after insertion
     */
    bubbleUp(index) {
        while (this.hasParent(index) && this.parent(index) < this.heap[index]) {
            const parentIndex = this.getParentIndex(index);
            this.swap(parentIndex, index);
            index = parentIndex;
        }
    }

    /**
     * EXTRACT MAX - Remove and return maximum element
     * Time Complexity: O(log n)
     */
    extractMax() {
        if (this.isEmpty()) {
            throw new Error("Heap is empty");
        }

        // Step 1: Save the maximum (root)
        const max = this.heap[0];

        // Step 2: Move last element to root
        this.heap[0] = this.heap.pop();

        // Step 3: Bubble down to maintain heap property
        if (!this.isEmpty()) {
            this.bubbleDown(0);
        }

        return max;
    }

    /**
     * BUBBLE DOWN - Move element down until heap property satisfied
     * Also known as: heapify, sift-down, sink
     */
    bubbleDown(index) {
        while (this.hasLeftChild(index)) {
            // Find the larger child
            let largerChildIndex = this.getLeftChildIndex(index);

            if (this.hasRightChild(index) &&
                this.rightChild(index) > this.leftChild(index)) {
                largerChildIndex = this.getRightChildIndex(index);
            }

            // If current node is larger than both children, we're done
            if (this.heap[index] >= this.heap[largerChildIndex]) {
                break;
            }

            // Swap with larger child and continue
            this.swap(index, largerChildIndex);
            index = largerChildIndex;
        }
    }

    /**
     * HEAPIFY - Recursive version of bubble down
     * Classical textbook implementation
     */
    heapify(index) {
        const left = this.getLeftChildIndex(index);
        const right = this.getRightChildIndex(index);
        let largest = index;

        if (left < this.heap.length && this.heap[left] > this.heap[largest]) {
            largest = left;
        }

        if (right < this.heap.length && this.heap[right] > this.heap[largest]) {
            largest = right;
        }

        if (largest !== index) {
            this.swap(index, largest);
            this.heapify(largest); // Recursive call
        }
    }

    /**
     * BUILD HEAP - Convert arbitrary array into heap
     * Time Complexity: O(n)
     */
    static buildHeap(array) {
        const heap = new MaxHeap();
        heap.heap = [...array];

        // Start from last non-leaf node and heapify down to root
        const startIndex = Math.floor(array.length / 2) - 1;

        for (let i = startIndex; i >= 0; i--) {
            heap.heapify(i);
        }

        return heap;
    }

    /**
     * INCREASE KEY - Increase value at given index
     * Time Complexity: O(log n)
     */
    increaseKey(index, newValue) {
        if (newValue < this.heap[index]) {
            throw new Error("New value is smaller than current");
        }

        this.heap[index] = newValue;
        this.bubbleUp(index);
    }

    /**
     * DECREASE KEY - Decrease value at given index
     * Time Complexity: O(log n)
     */
    decreaseKey(index, newValue) {
        if (newValue > this.heap[index]) {
            throw new Error("New value is larger than current");
        }

        this.heap[index] = newValue;
        this.bubbleDown(index);
    }

    /**
     * DELETE - Remove element at given index
     * Time Complexity: O(log n)
     */
    delete(index) {
        if (index < 0 || index >= this.heap.length) {
            throw new Error("Index out of bounds");
        }

        // Replace with last element
        const lastElement = this.heap.pop();

        if (index < this.heap.length) {
            const currentValue = this.heap[index];
            this.heap[index] = lastElement;

            // Decide whether to bubble up or down
            if (lastElement > currentValue) {
                this.bubbleUp(index);
            } else {
                this.bubbleDown(index);
            }
        }
    }

    /**
     * SEARCH - Find index of element (not efficient for heaps)
     * Time Complexity: O(n)
     */
    search(value) {
        for (let i = 0; i < this.heap.length; i++) {
            if (this.heap[i] === value) {
                return i;
            }
        }
        return -1;
    }

    // ─────────────────────────────────────────────────────────────────────
    //                    HEAP SORT (STATIC METHOD)
    // ─────────────────────────────────────────────────────────────────────

    /**
     * HEAP SORT - Sort array using heap
     * Time Complexity: O(n log n)
     * Space Complexity: O(1) - in-place
     */
    static heapSort(array) {
        const n = array.length;

        // Phase 1: Build max heap
        for (let i = Math.floor(n / 2) - 1; i >= 0; i--) {
            MaxHeap._heapifyArray(array, n, i);
        }

        // Phase 2: Extract elements one by one
        for (let i = n - 1; i > 0; i--) {
            // Move current root to end
            [array[0], array[i]] = [array[i], array[0]];

            // Heapify reduced heap
            MaxHeap._heapifyArray(array, i, 0);
        }

        return array;
    }

    static _heapifyArray(array, heapSize, index) {
        let largest = index;
        const left = 2 * index + 1;
        const right = 2 * index + 2;

        if (left < heapSize && array[left] > array[largest]) {
            largest = left;
        }

        if (right < heapSize && array[right] > array[largest]) {
            largest = right;
        }

        if (largest !== index) {
            [array[index], array[largest]] = [array[largest], array[index]];
            MaxHeap._heapifyArray(array, heapSize, largest);
        }
    }

    // ─────────────────────────────────────────────────────────────────────
    //                    VISUALIZATION METHODS
    // ─────────────────────────────────────────────────────────────────────

    print() {
        console.log("Heap array:", this.heap);
    }

    visualize() {
        if (this.isEmpty()) {
            console.log("Empty heap");
            return;
        }

        const height = Math.floor(Math.log2(this.heap.length)) + 1;
        let index = 0;

        console.log("\n" + "═".repeat(50));
        console.log("           HEAP VISUALIZATION");
        console.log("═".repeat(50));

        for (let level = 0; level < height; level++) {
            const nodesInLevel = Math.pow(2, level);
            const spacing = Math.pow(2, height - level) - 1;
            let line = " ".repeat(spacing * 2);

            for (let i = 0; i < nodesInLevel && index < this.heap.length; i++) {
                line += String(this.heap[index]).padStart(3).padEnd(spacing * 4 + 3);
                index++;
            }
            console.log(line);
        }
        console.log("═".repeat(50) + "\n");
    }

    getArray() {
        return [...this.heap];
    }
}

//                         MIN HEAP IMPLEMENTATION

class MinHeap {
    constructor() {
        this.heap = [];
    }

    getParentIndex(i) {
        return Math.floor((i - 1) / 2);
    }
    getLeftChildIndex(i) {
        return 2 * i + 1;
    }
    getRightChildIndex(i) {
        return 2 * i + 2;
    }

    swap(i, j) {
        [this.heap[i], this.heap[j]] = [this.heap[j], this.heap[i]];
    }

    peek() {
        if (this.heap.length === 0) throw new Error("Heap is empty");
        return this.heap[0];
    }

    size() {
        return this.heap.length;
    }
    isEmpty() {
        return this.heap.length === 0;
    }

    insert(value) {
        this.heap.push(value);
        this.bubbleUp(this.heap.length - 1);
        return this;
    }

    bubbleUp(index) {
        while (index > 0) {
            const parentIndex = this.getParentIndex(index);
            if (this.heap[parentIndex] <= this.heap[index]) break;
            this.swap(parentIndex, index);
            index = parentIndex;
        }
    }

    extractMin() {
        if (this.isEmpty()) throw new Error("Heap is empty");

        const min = this.heap[0];
        this.heap[0] = this.heap.pop();

        if (!this.isEmpty()) {
            this.bubbleDown(0);
        }

        return min;
    }

    bubbleDown(index) {
        while (this.getLeftChildIndex(index) < this.heap.length) {
            let smallerChildIndex = this.getLeftChildIndex(index);
            const rightIndex = this.getRightChildIndex(index);

            if (rightIndex < this.heap.length &&
                this.heap[rightIndex] < this.heap[smallerChildIndex]) {
                smallerChildIndex = rightIndex;
            }

            if (this.heap[index] <= this.heap[smallerChildIndex]) break;

            this.swap(index, smallerChildIndex);
            index = smallerChildIndex;
        }
    }

    static buildHeap(array) {
        const heap = new MinHeap();
        heap.heap = [...array];

        for (let i = Math.floor(array.length / 2) - 1; i >= 0; i--) {
            heap.bubbleDown(i);
        }

        return heap;
    }
}

class PriorityQueue {
    constructor(comparator = (a, b) => a.priority - b.priority) {
        this.heap = [];
        this.comparator = comparator; // Min-heap by default
    }

    enqueue(item, priority) {
        const node = {
            item,
            priority
        };
        this.heap.push(node);
        this.bubbleUp(this.heap.length - 1);
    }

    dequeue() {
        if (this.isEmpty()) return null;

        const result = this.heap[0];
        const last = this.heap.pop();

        if (this.heap.length > 0) {
            this.heap[0] = last;
            this.bubbleDown(0);
        }

        return result.item;
    }

    peek() {
        return this.isEmpty() ? null : this.heap[0].item;
    }

    isEmpty() {
        return this.heap.length === 0;
    }
    size() {
        return this.heap.length;
    }

    bubbleUp(index) {
        while (index > 0) {
            const parentIndex = Math.floor((index - 1) / 2);
            if (this.comparator(this.heap[parentIndex], this.heap[index]) <= 0) break;
            [this.heap[parentIndex], this.heap[index]] = [this.heap[index], this.heap[parentIndex]];
            index = parentIndex;
        }
    }

    bubbleDown(index) {
        while (2 * index + 1 < this.heap.length) {
            let smallest = 2 * index + 1;
            const right = 2 * index + 2;

            if (right < this.heap.length &&
                this.comparator(this.heap[right], this.heap[smallest]) < 0) {
                smallest = right;
            }

            if (this.comparator(this.heap[index], this.heap[smallest]) <= 0) break;

            [this.heap[index], this.heap[smallest]] = [this.heap[smallest], this.heap[index]];
            index = smallest;
        }
    }
}
```
