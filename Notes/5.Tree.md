# Trees: Complete Theory & Exam Guide 🌳

## PART 1: TREE FUNDAMENTALS

### 📖 Formal Definition

**Definition:** A tree is a finite set of one or more nodes such that:

1. There is a specially designated node called the root
2. The remaining nodes are partitioned into n ≥ 0 disjoint sets T₁, T₂, ..., Tₙ where each of these sets is a tree. T₁, T₂, ..., Tₙ are called the subtrees of the root.

**Alternative Definition (Graph Theory):**

A tree is a connected, acyclic (no cycles), undirected graph. A rooted tree has one designated root node with directed edges flowing away from it.

---

### 📚 Complete Terminology Dictionary

| TERM | DEFINITION |
|------|------------|
| Node | Fundamental unit containing data and links to children |
| Root | Topmost node with no parent (unique in each tree) |
| Parent | Node directly above another node |
| Child | Node directly below another node |
| Siblings | Nodes sharing the same parent |
| Leaf/External | Node with no children (terminal node) |
| Internal Node | Node with at least one child |
| Edge | Connection between parent and child |
| Path | Sequence of nodes connected by edges |
| Ancestor | Any node on path from root to that node |
| Descendant | Any node in the subtree rooted at that node |
| Depth | Number of edges from root to that node |
| Height (node) | Number of edges on longest path from node to leaf |
| Height (tree) | Height of root node = max depth of any node |
| Level | Set of all nodes at same depth (level = depth + 1) |
| Degree (node) | Number of children of that node |
| Degree (tree) | Maximum degree of any node in tree |
| Subtree | Tree formed by a node and all its descendants |
| Forest | Collection of disjoint trees |

### 📐 Important Mathematical Properties

#### Property 1: Edge Count

> **In a tree with n nodes, there are exactly (n - 1) edges**

**Proof:** Each node except root has exactly one incoming edge from parent.  
Therefore, edges = n - 1

---

#### Property 2: Minimum Height

> **Minimum height of tree with n nodes: h_min = ⌊log₂(n)⌋**

This occurs when tree is COMPLETE (filled level by level)

---

#### Property 3: Maximum Height

> **Maximum height of tree with n nodes: h_max = n - 1**

This occurs when tree degenerates into a linked list (skewed tree)

---

#### Property 4: Nodes at Level k

> **Maximum nodes at level k (depth k): 2^k for binary tree**

- Level 0 (root): 2⁰ = 1 node
- Level 1: 2¹ = 2 nodes
- Level 2: 2² = 4 nodes
- ...
- Level k: 2^k nodes

---

#### Property 5: Total Nodes in Perfect Binary Tree

> **Total nodes in perfect binary tree of height h:**
> 
> **n = 2⁰ + 2¹ + 2² + ... + 2^h = 2^(h+1) - 1**

**Proof:** Sum of geometric series with ratio 2  
S = a(r^n - 1)/(r - 1) = 1(2^(h+1) - 1)/(2-1) = 2^(h+1) - 1

---

#### Property 6: Height from Node Count

> **For perfect binary tree: h = log₂(n + 1) - 1**  
> **For complete binary tree: h = ⌊log₂(n)⌋**

---

#### Property 7: Leaf Count in Binary Tree

> **In a FULL binary tree:**  
> **If there are n₀ leaves and n₂ nodes with 2 children:**
> 
> **n₀ = n₂ + 1**

**Proof:**  
Let n₀ = nodes with 0 children (leaves)  
    n₁ = nodes with 1 child  
    n₂ = nodes with 2 children

Total nodes: n = n₀ + n₁ + n₂  
Total edges: n - 1 = n₁ + 2·n₂  (each non-leaf contributes edges)

For FULL binary tree, n₁ = 0, so:  
n - 1 = 2·n₂  
n₀ + n₂ - 1 = 2·n₂  
n₀ = n₂ + 1

## 🔄 Tree Traversals: Complete Theory

### Definition
Tree Traversal is the process of visiting (checking and/or updating) each node in a tree data structure, exactly once, in a systematic way.

---

### The Four Main Traversals:

```
                    ┌─────┐
                    │  A  │
                    └─────┘
                   /       \
              ┌─────┐     ┌─────┐
              │  B  │     │  C  │
              └─────┘     └─────┘
             /      \         \
        ┌─────┐  ┌─────┐   ┌─────┐
        │  D  │  │  E  │   │  F  │
        └─────┘  └─────┘   └─────┘
```

| TRAVERSAL | ORDER | RESULT | MNEMONIC |
|-----------|-------|--------|----------|
| Pre-order | Root→Left→Right | A,B,D,E,C,F | "Root First" (NLR) |
| In-order | Left→Root→Right | D,B,E,A,C,F | "Root Middle" (LNR) |
| Post-order | Left→Right→Root | D,E,B,F,C,A | "Root Last" (LRN) |
| Level-order | Level by level | A,B,C,D,E,F | "BFS" (uses Queue) |

---

### Detailed Algorithm Analysis:

#### 1. Pre-order Traversal (NLR)

```
PREORDER(node):
    if node is NULL:
        return
    VISIT(node)           ← Process current node FIRST
    PREORDER(node.left)   ← Then traverse left subtree
    PREORDER(node.right)  ← Finally traverse right subtree
```

**USE CASES:**
- Creating a copy of the tree
- Getting prefix expression of expression tree
- Serializing tree structure (can recreate tree from pre-order + in-order)

---

#### 2. In-order Traversal (LNR)

```
INORDER(node):
    if node is NULL:
        return
    INORDER(node.left)    ← First traverse left subtree
    VISIT(node)           ← Process current node in MIDDLE
    INORDER(node.right)   ← Finally traverse right subtree
```

**USE CASES:**
- Getting sorted sequence from BST (MOST IMPORTANT!)
- Getting infix expression from expression tree
- Validating if tree is BST

---

#### 3. Post-order Traversal (LRN)

```
POSTORDER(node):
    if node is NULL:
        return
    POSTORDER(node.left)  ← First traverse left subtree
    POSTORDER(node.right) ← Then traverse right subtree
    VISIT(node)           ← Process current node LAST
```

**USE CASES:**
- Deleting/freeing tree nodes (children before parent)
- Getting postfix expression from expression tree
- Calculating size of directories (children before parent folder)
- Evaluating expression trees

---

#### 4. Level-order Traversal (BFS)

```
LEVELORDER(root):
    if root is NULL:
        return
    queue = new Queue()
    queue.enqueue(root)
    
    while queue is not empty:
        node = queue.dequeue()
        VISIT(node)
        if node.left is not NULL:
            queue.enqueue(node.left)
        if node.right is not NULL:
            queue.enqueue(node.right)
```

**USE CASES:**
- Finding shortest path in unweighted tree
- Printing tree level by level
- Finding nodes at distance k from root
- Serialization of tree

---

### Traversal Complexity Analysis:

**All Traversals:**

- **Time Complexity:** O(n) - visit each node exactly once
- **Space Complexity:**
  - Recursive (Pre/In/Post): O(h) where h = height (call stack)
  - Level-order: O(w) where w = max width of tree

For balanced tree: h = O(log n), w = O(n/2) = O(n)  
For skewed tree: h = O(n), w = O(1)

## PART 2: BINARY SEARCH TREES (BST)

### 📖 Formal Definition

**Definition:** A Binary Search Tree is a binary tree that satisfies the BST Property:

For every node X in the tree:
1. All keys in the left subtree of X are less than X's key
2. All keys in the right subtree of X are greater than X's key
3. Both left and right subtrees are also BSTs

```
            BST PROPERTY
            
     All values      ┌───┐     All values
        < X    ←───  │ X │  ───→    > X
                     └───┘
                    /     \
              ┌─────┐     ┌─────┐
              │ LST │     │ RST │
              └─────┘     └─────┘
              (< X)        (> X)
```

---

## 🎯 BST Operations: Detailed Analysis

### 1. SEARCH Operation

**ALGORITHM: BST_SEARCH(root, key)**

**INPUT:**
- root - pointer to root node
- key - value to search for

**OUTPUT:** pointer to node containing key, or NULL if not found

**PSEUDOCODE:**

```
BST_SEARCH(root, key):
    if root == NULL or root.key == key:
        return root
    
    if key < root.key:
        return BST_SEARCH(root.left, key)    // Search left subtree
    else:
        return BST_SEARCH(root.right, key)   // Search right subtree
```

**ITERATIVE VERSION:**

```
BST_SEARCH_ITERATIVE(root, key):
    current = root
    while current != NULL:
        if key == current.key:
            return current
        else if key < current.key:
            current = current.left
        else:
            current = current.right
    return NULL
```

**COMPLEXITY:**
- **Best Case:** O(1) - Key is at root
- **Average Case:** O(log n) - Balanced tree
- **Worst Case:** O(n) - Skewed tree
- **Space:** O(h) - Recursive call stack, O(1) - Iterative version

---

### 2. INSERT Operation

**ALGORITHM: BST_INSERT(root, key)**

**CONCEPT:** New node is ALWAYS inserted as a LEAF

**PSEUDOCODE:**

```
BST_INSERT(root, key):
    if root == NULL:
        return new Node(key)          // Create new leaf node
    
    if key < root.key:
        root.left = BST_INSERT(root.left, key)
    else if key > root.key:
        root.right = BST_INSERT(root.right, key)
    // If key == root.key, do nothing (no duplicates)
    
    return root
```

**EXAMPLE: Insert 25 into BST**

```
        ┌────┐                         ┌────┐
        │ 50 │                         │ 50 │
        └────┘                         └────┘
       /      \                       /      \
   ┌────┐   ┌────┐      →        ┌────┐   ┌────┐
   │ 30 │   │ 70 │               │ 30 │   │ 70 │
   └────┘   └────┘               └────┘   └────┘
   /    \                        /    \
┌────┐ ┌────┐                ┌────┐ ┌────┐
│ 20 │ │ 40 │                │ 20 │ │ 40 │
└────┘ └────┘                └────┘ └────┘
                                \
                              ┌────┐
                              │ 25 │  ← New node (always leaf!)
                              └────┘

Path: 50 → 30 → 20 → (right of 20) = 25
```

---

### 3. DELETE Operation (Most Complex!)

**ALGORITHM: BST_DELETE(root, key)**

**THREE CASES TO HANDLE:**

**CASE 1: Node to delete is a LEAF (no children)**
- → Simply remove the node

**CASE 2: Node to delete has ONE CHILD**
- → Replace node with its child

**CASE 3: Node to delete has TWO CHILDREN**
- → Replace with INORDER SUCCESSOR (or predecessor)
- → Delete the successor from its original position

---

#### CASE 1: Deleting a Leaf Node

```
Delete 20:

        ┌────┐                         ┌────┐
        │ 50 │                         │ 50 │
        └────┘                         └────┘
       /      \          →            /      \
   ┌────┐   ┌────┐               ┌────┐   ┌────┐
   │ 30 │   │ 70 │               │ 30 │   │ 70 │
   └────┘   └────┘               └────┘   └────┘
   /                                  
┌────┐                          Just remove it!
│ 20 │ ← DELETE THIS            
└────┘
```

---

#### CASE 2: Deleting Node with One Child

```
Delete 30 (has one child: 20):

        ┌────┐                         ┌────┐
        │ 50 │                         │ 50 │
        └────┘                         └────┘
       /      \          →            /      \
   ┌────┐   ┌────┐               ┌────┐   ┌────┐
   │ 30 │   │ 70 │               │ 20 │   │ 70 │
   └────┘   └────┘               └────┘   └────┘
   /                                  
┌────┐                          Replace 30 with its child 20
│ 20 │                          (bypass the deleted node)
└────┘
```

---

#### CASE 3: Deleting Node with Two Children

```
Delete 50 (has two children: 30 and 70):

STEP 1: Find inorder successor (smallest in right subtree)
        Inorder successor of 50 = 60

        ┌────┐                      
        │ 50 │  ← DELETE THIS       
        └────┘                      
       /      \                     
   ┌────┐   ┌────┐                  
   │ 30 │   │ 70 │                  
   └────┘   └────┘                  
           /                        
       ┌────┐                       
       │ 60 │  ← INORDER SUCCESSOR  
       └────┘                       

STEP 2: Copy successor's value to node being deleted

        ┌────┐                      
        │ 60 │  ← Changed from 50   
        └────┘                      
       /      \                     
   ┌────┐   ┌────┐                  
   │ 30 │   │ 70 │                  
   └────┘   └────┘                  
           /                        
       ┌────┐                       
       │ 60 │  ← Now delete this (Case 1 or 2)
       └────┘                       

STEP 3: Delete the successor node

        ┌────┐
        │ 60 │  ← New root!
        └────┘
       /      \
   ┌────┐   ┌────┐
   │ 30 │   │ 70 │
   └────┘   └────┘

BST property maintained! ✓
```

---

### Why Inorder Successor?

**INORDER SUCCESSOR = Smallest node in RIGHT subtree**  
**= Leftmost node of right subtree**

**WHY IT WORKS:**
- Successor is GREATER than all nodes in left subtree of deleted node ✓
- Successor is SMALLER than all other nodes in right subtree ✓
- Therefore, it can replace deleted node and maintain BST property! ✓

**ALTERNATIVE: Use INORDER PREDECESSOR**  
= Largest node in LEFT subtree = Rightmost node of left subtree

---

### Complete Delete Algorithm:

```
BST_DELETE(root, key):
    if root == NULL:
        return root
    
    // FIND THE NODE
    if key < root.key:
        root.left = BST_DELETE(root.left, key)
    else if key > root.key:
        root.right = BST_DELETE(root.right, key)
    else:
        // FOUND THE NODE TO DELETE
        
        // Case 1 & 2: No child or one child
        if root.left == NULL:
            return root.right
        else if root.right == NULL:
            return root.left
        
        // Case 3: Two children
        // Find inorder successor (smallest in right subtree)
        successor = FIND_MIN(root.right)
        
        // Copy successor's value
        root.key = successor.key
        
        // Delete the successor
        root.right = BST_DELETE(root.right, successor.key)
    
    return root

FIND_MIN(node):
    while node.left != NULL:
        node = node.left
    return node
```

## 💻 Complete BST Implementation with Theory Notes

```javascript
/*
 * ═══════════════════════════════════════════════════════════════════════════
 * BINARY SEARCH TREE - COMPLETE IMPLEMENTATION
 * ═══════════════════════════════════════════════════════════════════════════
 * 
 * PROPERTIES:
 * - Each node has at most 2 children
 * - Left subtree contains only nodes with keys < parent
 * - Right subtree contains only nodes with keys > parent
 * - Both subtrees are also BSTs
 * 
 * TIME COMPLEXITIES:
 * ┌────────────────────────────────────────────────────┐
 * │ Operation    │ Average    │ Worst (skewed)        │
 * ├────────────────────────────────────────────────────┤
 * │ Search       │ O(log n)   │ O(n)                  │
 * │ Insert       │ O(log n)   │ O(n)                  │
 * │ Delete       │ O(log n)   │ O(n)                  │
 * │ Min/Max      │ O(log n)   │ O(n)                  │
 * │ Traversal    │ O(n)       │ O(n)                  │
 * └────────────────────────────────────────────────────┘
 * 
 * SPACE COMPLEXITY:
 * - Tree storage: O(n)
 * - Recursive operations: O(h) where h = height
 */

class BSTNode {
    constructor(key, value = key) {
        this.key = key;           // For comparison
        this.value = value;       // Actual data stored
        this.left = null;         // Left child pointer
        this.right = null;        // Right child pointer
    }
}

class BinarySearchTree {
    constructor() {
        this.root = null;
        this.size = 0;
    }
    
    // ═══════════════════════════════════════════════════════════════════
    // INSERT OPERATION
    // ═══════════════════════════════════════════════════════════════════
    /*
     * Algorithm: Always insert as a leaf node
     * 1. If tree is empty, new node becomes root
     * 2. Otherwise, compare with current node:
     *    - If smaller, go left
     *    - If larger, go right
     * 3. Repeat until finding empty spot
     * 
     * Time: O(h) where h = height of tree
     * Space: O(h) for recursive call stack
     */
    insert(key, value = key) {
        const newNode = new BSTNode(key, value);
        
        if (this.root === null) {
            this.root = newNode;
            this.size++;
            return this;
        }
        
        this.root = this._insertRecursive(this.root, newNode);
        this.size++;
        return this;
    }
    
    _insertRecursive(node, newNode) {
        if (node === null) {
            return newNode;
        }
        
        if (newNode.key < node.key) {
            node.left = this._insertRecursive(node.left, newNode);
        } else if (newNode.key > node.key) {
            node.right = this._insertRecursive(node.right, newNode);
        }
        // If keys are equal, we don't insert (no duplicates)
        
        return node;
    }
    
    // Iterative version (more space-efficient)
    insertIterative(key, value = key) {
        const newNode = new BSTNode(key, value);
        
        if (this.root === null) {
            this.root = newNode;
            this.size++;
            return this;
        }
        
        let current = this.root;
        let parent = null;
        
        while (current !== null) {
            parent = current;
            if (key < current.key) {
                current = current.left;
            } else if (key > current.key) {
                current = current.right;
            } else {
                return this; // Duplicate, don't insert
            }
        }
        
        if (key < parent.key) {
            parent.left = newNode;
        } else {
            parent.right = newNode;
        }
        
        this.size++;
        return this;
    }
    
    // ═══════════════════════════════════════════════════════════════════
    // SEARCH OPERATION
    // ═══════════════════════════════════════════════════════════════════
    /*
     * Algorithm: Binary search through tree
     * 1. Start at root
     * 2. If current node is null, key not found
     * 3. If key matches, return node
     * 4. If key is smaller, search left subtree
     * 5. If key is larger, search right subtree
     * 
     * Why efficient: Eliminates half the remaining tree at each step
     */
    search(key) {
        return this._searchRecursive(this.root, key);
    }
    
    _searchRecursive(node, key) {
        // Base cases
        if (node === null) return null;
        if (key === node.key) return node;
        
        // Recursive cases
        if (key < node.key) {
            return this._searchRecursive(node.left, key);
        } else {
            return this._searchRecursive(node.right, key);
        }
    }
    
    searchIterative(key) {
        let current = this.root;
        
        while (current !== null) {
            if (key === current.key) {
                return current;
            } else if (key < current.key) {
                current = current.left;
            } else {
                current = current.right;
            }
        }
        
        return null;
    }
    
    contains(key) {
        return this.search(key) !== null;
    }
    
    // ═══════════════════════════════════════════════════════════════════
    // DELETE OPERATION
    // ═══════════════════════════════════════════════════════════════════
    /*
     * Three cases:
     * 
     * CASE 1: Node is a leaf (no children)
     *   → Simply remove the node
     *   
     * CASE 2: Node has one child
     *   → Replace node with its child (bypass)
     *   
     * CASE 3: Node has two children
     *   → Find inorder successor (min of right subtree)
     *   → Copy successor's key to current node
     *   → Delete the successor (which is Case 1 or 2)
     */
    delete(key) {
        this.root = this._deleteRecursive(this.root, key);
        return this;
    }
    
    _deleteRecursive(node, key) {
        // Base case: key not found
        if (node === null) {
            return null;
        }
        
        // Traverse to find the node
        if (key < node.key) {
            node.left = this._deleteRecursive(node.left, key);
        } else if (key > node.key) {
            node.right = this._deleteRecursive(node.right, key);
        } else {
            // Found the node to delete!
            
            // CASE 1: Leaf node
            if (node.left === null && node.right === null) {
                this.size--;
                return null;
            }
            
            // CASE 2a: Only right child
            if (node.left === null) {
                this.size--;
                return node.right;
            }
            
            // CASE 2b: Only left child
            if (node.right === null) {
                this.size--;
                return node.left;
            }
            
            // CASE 3: Two children
            // Find inorder successor (minimum in right subtree)
            const successor = this._findMin(node.right);
            
            // Copy successor's data to this node
            node.key = successor.key;
            node.value = successor.value;
            
            // Delete the successor (it's guaranteed to have ≤1 child)
            node.right = this._deleteRecursive(node.right, successor.key);
        }
        
        return node;
    }
    
    // ═══════════════════════════════════════════════════════════════════
    // FIND MIN/MAX OPERATIONS
    // ═══════════════════════════════════════════════════════════════════
    /*
     * MIN: Leftmost node (keep going left)
     * MAX: Rightmost node (keep going right)
     * 
     * Why: BST property ensures smallest is leftmost, largest is rightmost
     */
    _findMin(node) {
        while (node.left !== null) {
            node = node.left;
        }
        return node;
    }
    
    _findMax(node) {
        while (node.right !== null) {
            node = node.right;
        }
        return node;
    }
    
    findMin() {
        if (this.root === null) return null;
        return this._findMin(this.root);
    }
    
    findMax() {
        if (this.root === null) return null;
        return this._findMax(this.root);
    }
    
    // ═══════════════════════════════════════════════════════════════════
    // TREE TRAVERSALS
    // ═══════════════════════════════════════════════════════════════════
    
    // In-order: Left → Root → Right (gives SORTED order for BST!)
    inOrderTraversal(callback) {
        const result = [];
        this._inOrder(this.root, callback || (node => result.push(node.key)));
        return callback ? undefined : result;
    }
    
    _inOrder(node, callback) {
        if (node !== null) {
            this._inOrder(node.left, callback);
            callback(node);
            this._inOrder(node.right, callback);
        }
    }
    
    // Pre-order: Root → Left → Right
    preOrderTraversal(callback) {
        const result = [];
        this._preOrder(this.root, callback || (node => result.push(node.key)));
        return callback ? undefined : result;
    }
    
    _preOrder(node, callback) {
        if (node !== null) {
            callback(node);
            this._preOrder(node.left, callback);
            this._preOrder(node.right, callback);
        }
    }
    
    // Post-order: Left → Right → Root
    postOrderTraversal(callback) {
        const result = [];
        this._postOrder(this.root, callback || (node => result.push(node.key)));
        return callback ? undefined : result;
    }
    
    _postOrder(node, callback) {
        if (node !== null) {
            this._postOrder(node.left, callback);
            this._postOrder(node.right, callback);
            callback(node);
        }
    }
    
    // Level-order: BFS traversal
    levelOrderTraversal(callback) {
        const result = [];
        if (this.root === null) return result;
        
        const queue = [this.root];
        
        while (queue.length > 0) {
            const node = queue.shift();
            if (callback) {
                callback(node);
            } else {
                result.push(node.key);
            }
            
            if (node.left) queue.push(node.left);
            if (node.right) queue.push(node.right);
        }
        
        return callback ? undefined : result;
    }
    
    // ═══════════════════════════════════════════════════════════════════
    // UTILITY FUNCTIONS
    // ═══════════════════════════════════════════════════════════════════
    
    // Height of tree (longest path from root to leaf)
    height() {
        return this._height(this.root);
    }
    
    _height(node) {
        if (node === null) return -1; // Empty tree has height -1
        
        const leftHeight = this._height(node.left);
        const rightHeight = this._height(node.right);
        
        return 1 + Math.max(leftHeight, rightHeight);
    }
    
    // Check if tree is balanced (for all nodes, height diff ≤ 1)
    isBalanced() {
        return this._checkBalanced(this.root) !== -Infinity;
    }
    
    _checkBalanced(node) {
        if (node === null) return -1;
        
        const leftHeight = this._checkBalanced(node.left);
        if (leftHeight === -Infinity) return -Infinity;
        
        const rightHeight = this._checkBalanced(node.right);
        if (rightHeight === -Infinity) return -Infinity;
        
        if (Math.abs(leftHeight - rightHeight) > 1) {
            return -Infinity; // Unbalanced
        }
        
        return 1 + Math.max(leftHeight, rightHeight);
    }
    
    // Validate BST property
    isValidBST() {
        return this._isValidBST(this.root, -Infinity, Infinity);
    }
    
    _isValidBST(node, min, max) {
        if (node === null) return true;
        
        if (node.key <= min || node.key >= max) {
            return false;
        }
        
        return this._isValidBST(node.left, min, node.key) &&
               this._isValidBST(node.right, node.key, max);
    }
    
    // Count nodes
    countNodes() {
        return this._countNodes(this.root);
    }
    
    _countNodes(node) {
        if (node === null) return 0;
        return 1 + this._countNodes(node.left) + this._countNodes(node.right);
    }
    
    // Find kth smallest element
    kthSmallest(k) {
        let count = 0;
        let result = null;
        
        const findKth = (node) => {
            if (node === null || result !== null) return;
            
            findKth(node.left);
            
            count++;
            if (count === k) {
                result = node.key;
                return;
            }
            
            findKth(node.right);
        };
        
        findKth(this.root);
        return result;
    }
    
    // Find Lowest Common Ancestor
    lowestCommonAncestor(key1, key2) {
        return this._lca(this.root, key1, key2);
    }
    
    _lca(node, key1, key2) {
        if (node === null) return null;
        
        // If both keys are smaller, LCA is in left subtree
        if (key1 < node.key && key2 < node.key) {
            return this._lca(node.left, key1, key2);
        }
        
        // If both keys are larger, LCA is in right subtree
        if (key1 > node.key && key2 > node.key) {
            return this._lca(node.right, key1, key2);
        }
        
        // One key on each side (or one equals current), current is LCA
        return node;
    }
    
    // ═══════════════════════════════════════════════════════════════════
    // VISUALIZATION
    // ═══════════════════════════════════════════════════════════════════
    
    visualize() {
        console.log("\n" + "═".repeat(50));
        console.log("BST Visualization");
        console.log("═".repeat(50));
        
        if (this.root === null) {
            console.log("(empty tree)");
            return;
        }
        
        this._visualize(this.root, "", true);

    }

                );

    }
}
```

## PART 3: AVL TREES

### 📖 Formal Definition

**Definition:** An AVL tree (named after inventors Adelson-Velsky and Landis, 1962) is a self-balancing Binary Search Tree where the balance factor of every node is in the range [-1, 0, +1].

**BALANCE FACTOR (BF) = Height(Left Subtree) - Height(Right Subtree)**

**Valid Balance Factors: {-1, 0, +1}**

- **BF = -1:** Right subtree is 1 level deeper (right-heavy)
- **BF = 0:** Left and right subtrees have equal height (balanced)
- **BF = +1:** Left subtree is 1 level deeper (left-heavy)
- **BF < -1 or BF > +1:** UNBALANCED → Rotation needed!

---

### 📐 Mathematical Properties of AVL Trees

#### Height Bounds

**THEOREM:** The height h of an AVL tree with n nodes satisfies:

**log₂(n + 1) - 1  ≤  h  <  1.44 log₂(n + 2) - 0.328**

**SIMPLIFIED: h = O(log n)**

This guarantees O(log n) operations!

---

#### Minimum Nodes for Height h

**FIBONACCI-LIKE PROPERTY:**

N(h) = minimum number of nodes in AVL tree of height h

- N(0) = 1
- N(1) = 2
- N(h) = N(h-1) + N(h-2) + 1   for h ≥ 2

| Height h | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|----------|---|---|---|---|---|---|---|---|
| N(h) | 1 | 2 | 4 | 7 | 12 | 20 | 33 | 54 |

**N(h) ≈ φ^(h+2) / √5  where φ = (1 + √5) / 2 ≈ 1.618 (Golden Ratio)**

---

#### Proof of O(log n) Height

```
Since N(h) ≈ φ^(h+2) / √5

For a tree with n nodes: n ≥ N(h) ≈ φ^(h+2) / √5

Taking logarithm:
    log_φ(n) ≥ h + 2 - log_φ(√5)
    h ≤ log_φ(n) - 2 + log_φ(√5)
    h ≤ log_φ(n) + constant
    h = O(log_φ(n)) = O(log n)

Since log_φ(n) = log₂(n) / log₂(φ) ≈ 1.44 log₂(n)

Height is at most 1.44 times that of perfectly balanced tree.
```

## 🔄 The Four Rotation Cases

### Understanding When Each Rotation Applies:

```
                        AVL ROTATION DECISION TREE
                        
  Is node unbalanced? (|BF| > 1)
         │
         ├─── NO ──→ No rotation needed
         │
         └─── YES ──→ Which side is heavy?
                           │
         ┌─────────────────┴─────────────────┐
         │                                   │
    LEFT HEAVY (BF > 1)              RIGHT HEAVY (BF < -1)
         │                                   │
    Check left child's BF            Check right child's BF
         │                                   │
    ┌────┴────┐                         ┌────┴────┐
    │         │                         │         │

  CASE      CASE                      CASE      CASE
    │         │                         │         │
  RIGHT    LEFT-RIGHT                LEFT     RIGHT-LEFT
 ROTATE     ROTATE                  ROTATE      ROTATE
```

### CASE 1: LL (Left-Left) → Single Right Rotation

**When:** Node is left-heavy (BF > 1) AND left child is left-heavy or balanced (BF ≥ 0)

**Cause:** Insertion in left subtree of left child

```
BEFORE:                          AFTER Right Rotation:
        
        ┌─────┐                        ┌─────┐
        │  z  │ BF=2                   │  y  │ BF=0
        └─────┘                        └─────┘
       /                              /       \
   ┌─────┐                        ┌─────┐   ┌─────┐
   │  y  │ BF=1                   │  x  │   │  z  │
   └─────┘                        └─────┘   └─────┘
  /       \                       /    \       \
┌─────┐  ┌───┐                 ┌───┐ ┌───┐   ┌───┐
│  x  │  │ T3│                 │T1 │ │T2 │   │T3 │
└─────┘  └───┘                 └───┘ └───┘   └───┘
/     \
┌───┐ ┌───┐
│T1 │ │T2 │
└───┘ └───┘

ALGORITHM (Right Rotation around z):
─────────────────────────────────────
1. y becomes new root
2. z becomes right child of y
3. T3 (right subtree of y) becomes left child of z
4. T1, T2, x stay unchanged
```

**Pseudocode:**

```
RIGHT_ROTATE(z):
    y = z.left
    T3 = y.right
    
    // Perform rotation
    y.right = z
    z.left = T3
    
    // Update heights
    z.height = 1 + max(height(z.left), height(z.right))
    y.height = 1 + max(height(y.left), height(y.right))
    
    return y  // New root
```

### CASE 3: LR (Left-Right) → Left Rotation then Right Rotation

**When:** Node is left-heavy (BF > 1) AND left child is right-heavy (BF < 0)

**Cause:** Insertion in right subtree of left child (creates zig-zag)

```
BEFORE:                 AFTER LEFT ROTATE(y):        AFTER RIGHT ROTATE(z):

   ┌─────┐              ┌─────┐                      ┌─────┐   ┌─────┐

   └─────┘              └─────┘                      └─────┘   └─────┘
  /       \            /       \                     /    \       \
┌───┐  ┌─────┐      ┌─────┐  ┌───┐                ┌───┐ ┌───┐   ┌───┐
│T1 │  │  x  │      │  y  │  │T3 │                │T1 │ │T2 │   │T3 │
└───┘  └─────┘      └─────┘  └───┘                └───┘ └───┘   └───┘

    └───┘  └───┘ └───┘ └───┘

Step 1: Left rotate around y (straighten the zig-zag)
Step 2: Right rotate around z (balance the tree)
```

```
LR_ROTATE(z):
    // Step 1: Left rotate the left child
    z.left = LEFT_ROTATE(z.left)
    
    // Step 2: Right rotate the root
    return RIGHT_ROTATE(z)
```

## 💻 Complete AVL Tree Implementation with Extensive Comments

```javascript
/*
 * ═══════════════════════════════════════════════════════════════════════════════
 * AVL TREE - COMPLETE IMPLEMENTATION WITH THEORY
 * ═══════════════════════════════════════════════════════════════════════════════
 * 
 * DEFINITION:
 * An AVL tree is a self-balancing BST where for every node, the heights of
 * left and right subtrees differ by at most 1.
 * 
 * BALANCE FACTOR = height(left subtree) - height(right subtree)
 * Must be in {-1, 0, +1} for all nodes
 * 
 * TIME COMPLEXITIES (ALL GUARANTEED):
 * ┌────────────────────────────────────────────────────┐
 * │ Operation        │ Time Complexity                │
 * ├────────────────────────────────────────────────────┤
 * │ Search           │ O(log n)                       │
 * │ Insert           │ O(log n)                       │
 * │ Delete           │ O(log n)                       │
 * │ Find Min/Max     │ O(log n)                       │
 * │ Rotation         │ O(1)                           │
 * └────────────────────────────────────────────────────┘
 * 
 * SPACE COMPLEXITY:
 * - Tree storage: O(n)
 * - Each node: O(1) extra for height
 * - Operations: O(log n) for recursion stack
 * 
 * ADVANTAGES OVER BST:
 * - Guaranteed O(log n) operations (no O(n) worst case)
 * - Height always ~ 1.44 log₂(n)
 * 
 * DISADVANTAGES:
 * - More complex implementation
 * - Extra space for height in each node
 * - Rotations have overhead (but still O(1))
 */

class AVLNode {
    constructor(key, value = key) {
        this.key = key;
        this.value = value;
        this.left = null;
        this.right = null;
        this.height = 1;  // New node is initially a leaf
    }
}

class AVLTree {
    constructor() {
        this.root = null;
        this.rotationCount = 0;  // For analysis
    }
    
    // ═══════════════════════════════════════════════════════════════════════════
    // HELPER FUNCTIONS
    // ═══════════════════════════════════════════════════════════════════════════
    
    /*
     * Get height of a node
     * Convention: null node has height 0, leaf has height 1
     * Some implementations use height 0 for leaf, -1 for null
     */
    getHeight(node) {
        if (node === null) return 0;
        return node.height;
    }
    
    /*
     * Calculate balance factor
     * BF > 0: Left-heavy
     * BF < 0: Right-heavy
     * BF = 0: Perfectly balanced
     */
    getBalanceFactor(node) {
        if (node === null) return 0;
        return this.getHeight(node.left) - this.getHeight(node.right);
    }
    
    /*
     * Update height after rotation or insertion
     * Height = 1 + max(left height, right height)
     */
    updateHeight(node) {
        if (node === null) return;
        node.height = 1 + Math.max(
            this.getHeight(node.left),
            this.getHeight(node.right)
        );
    }
    
    // ═══════════════════════════════════════════════════════════════════════════
    // ROTATIONS
    // ═══════════════════════════════════════════════════════════════════════════
    
    /*
     * RIGHT ROTATION (for LL case)
     * 
     *       y                             x
     *      / \                           / \
     *     x   T3   ─────────────→      T1   y
     *    / \                               / \
     *   T1  T2                           T2  T3
     * 
     * Time Complexity: O(1)
     * Space Complexity: O(1)
     */
    rightRotate(y) {
        console.log(`  ↻ Right Rotation on node ${y.key}`);
        this.rotationCount++;
        
        // Store references
        const x = y.left;
        const T2 = x.right;
        
        // Perform rotation
        x.right = y;
        y.left = T2;
        
        // Update heights (y first since it's now a child)
        this.updateHeight(y);
        this.updateHeight(x);
        
        // Return new root of this subtree
        return x;
    }
    
    /*
     * LEFT ROTATION (for RR case)
     * 
     *     x                              y
     *    / \                            / \
     *   T1  y     ─────────────→      x   T3
     *      / \                       / \
     *     T2  T3                   T1  T2
     * 
     * Time Complexity: O(1)
     * Space Complexity: O(1)
     */
    leftRotate(x) {
        console.log(`  ↺ Left Rotation on node ${x.key}`);
        this.rotationCount++;
        
        // Store references
        const y = x.right;
        const T2 = y.left;
        
        // Perform rotation
        y.left = x;
        x.right = T2;
        
        // Update heights (x first since it's now a child)
        this.updateHeight(x);
        this.updateHeight(y);
        
        // Return new root of this subtree
        return y;
    }
    
    // ═══════════════════════════════════════════════════════════════════════════
    // BALANCE FUNCTION
    // ═══════════════════════════════════════════════════════════════════════════
    
    /*
     * Check and fix balance at a node
     * Called after every insert/delete
     * 
     * Four cases to handle:
     * 1. LL: BF > 1 and left child BF ≥ 0 → Right rotation
     * 2. LR: BF > 1 and left child BF < 0 → Left-Right rotation
     * 3. RR: BF < -1 and right child BF ≤ 0 → Left rotation
     * 4. RL: BF < -1 and right child BF > 0 → Right-Left rotation
     */
    rebalance(node) {
        // First update height
        this.updateHeight(node);
        
        // Get balance factor
        const bf = this.getBalanceFactor(node);
        
        // Left Heavy (bf > 1)
        if (bf > 1) {
            const leftBF = this.getBalanceFactor(node.left);
            
            // LL Case: Left child is left-heavy or balanced
            if (leftBF >= 0) {
                console.log(`  📍 LL Case detected at node ${node.key} (BF=${bf})`);
                return this.rightRotate(node);
            }
            // LR Case: Left child is right-heavy
            else {
                console.log(`  📍 LR Case detected at node ${node.key} (BF=${bf})`);
                node.left = this.leftRotate(node.left);
                return this.rightRotate(node);
            }
        }
        
        // Right Heavy (bf < -1)
        if (bf < -1) {
            const rightBF = this.getBalanceFactor(node.right);
            
            // RR Case: Right child is right-heavy or balanced
            if (rightBF <= 0) {
                console.log(`  📍 RR Case detected at node ${node.key} (BF=${bf})`);
                return this.leftRotate(node);
            }
            // RL Case: Right child is left-heavy
            else {
                console.log(`  📍 RL Case detected at node ${node.key} (BF=${bf})`);
                node.right = this.rightRotate(node.right);
                return this.leftRotate(node);
            }
        }
        
        // Node is balanced, no rotation needed
        return node;
    }
    
    // ═══════════════════════════════════════════════════════════════════════════
    // INSERT OPERATION
    // ═══════════════════════════════════════════════════════════════════════════
    
    /*
     * AVL Insert Algorithm:
     * 1. Perform standard BST insertion
     * 2. Update height of current node
     * 3. Get balance factor
     * 4. If unbalanced, perform appropriate rotation
     * 5. Return new root of subtree
     * 
     * Time Complexity: O(log n) - guaranteed
     * - O(log n) to find insertion point
     * - O(1) for rotation
     * - O(log n) for height updates on path back up
     */
    insert(key, value = key) {
        console.log(`\n📥 Inserting ${key}...`);
        this.root = this._insertRecursive(this.root, key, value);
        return this;
    }
    
    _insertRecursive(node, key, value) {
        // Step 1: Standard BST insertion
        if (node === null) {
            console.log(`   Created new node: ${key}`);
            return new AVLNode(key, value);
        }
        
        if (key < node.key) {
            node.left = this._insertRecursive(node.left, key, value);
        } else if (key > node.key) {
            node.right = this._insertRecursive(node.right, key, value);
        } else {
            // Duplicate key, don't insert
            console.log(`   Duplicate key ${key}, not inserted`);
            return node;
        }
        
        // Step 2-4: Update height and rebalance
        return this.rebalance(node);
    }
    
    // ═══════════════════════════════════════════════════════════════════════════
    // DELETE OPERATION
    // ═══════════════════════════════════════════════════════════════════════════
    
    /*
     * AVL Delete Algorithm:
     * 1. Perform standard BST deletion
     * 2. Update heights on the path back up
     * 3. Rebalance each node on the path
     * 
     * Note: Unlike insert where at most 2 rotations are needed,
     *       delete may require O(log n) rotations!
     * 
     * Time Complexity: O(log n)
     */
    delete(key) {
        console.log(`\n📤 Deleting ${key}...`);
        this.root = this._deleteRecursive(this.root, key);
        return this;
    }
    
    _deleteRecursive(node, key) {
        // Step 1: Standard BST deletion
        if (node === null) {
            console.log(`   Key ${key} not found`);
            return null;
        }
        
        if (key < node.key) {
            node.left = this._deleteRecursive(node.left, key);
        } else if (key > node.key) {
            node.right = this._deleteRecursive(node.right, key);
        } else {
            // Found the node to delete
            console.log(`   Found node ${key} to delete`);
            
            // Case 1 & 2: Node with one or no child
            if (node.left === null) {
                return node.right;
            } else if (node.right === null) {
                return node.left;
            }
            
            // Case 3: Node with two children
            // Get inorder successor (smallest in right subtree)
            const successor = this._findMin(node.right);
            console.log(`   Replacing with successor ${successor.key}`);
            
            // Copy successor's data
            node.key = successor.key;
            node.value = successor.value;
            
            // Delete the successor
            node.right = this._deleteRecursive(node.right, successor.key);
        }
        
        // Step 2-3: Rebalance
        return this.rebalance(node);
    }
    
    _findMin(node) {
        while (node.left !== null) {
            node = node.left;
        }
        return node;
    }
    
    // ═══════════════════════════════════════════════════════════════════════════
    // SEARCH AND OTHER OPERATIONS
    // ═══════════════════════════════════════════════════════════════════════════
    
    search(key) {
        return this._search(this.root, key);
    }
    
    _search(node, key) {
        if (node === null || node.key === key) {
            return node;
        }
        
        if (key < node.key) {
            return this._search(node.left, key);
        }
        return this._search(node.right, key);
    }
    
    // ═══════════════════════════════════════════════════════════════════════════
    // TRAVERSALS
    // ═══════════════════════════════════════════════════════════════════════════
    
    inOrder(node = this.root, result = []) {
        if (node !== null) {
            this.inOrder(node.left, result);
            result.push(node.key);
            this.inOrder(node.right, result);
        }
        return result;
    }
    
    // ═══════════════════════════════════════════════════════════════════════════
    // VALIDATION
    // ═══════════════════════════════════════════════════════════════════════════
    
    /*
     * Verify that tree maintains AVL property
     * For every node, |BF| ≤ 1
     */
    isValidAVL() {
        return this._isValidAVL(this.root);
    }
    
    _isValidAVL(node) {
        if (node === null) return true;
        
        const bf = this.getBalanceFactor(node);
        if (Math.abs(bf) > 1) {
            console.log(`Invalid: Node ${node.key} has BF=${bf}`);
            return false;
        }
        
        return this._isValidAVL(node.left) && this._isValidAVL(node.right);
    }
    
    // ═══════════════════════════════════════════════════════════════════════════
    // VISUALIZATION
    // ═══════════════════════════════════════════════════════════════════════════
    
    visualize() {
        console.log("\n" + "═".repeat(60));
        console.log("AVL Tree Visualization");
        console.log("═".repeat(60));
        
        if (this.root === null) {
            console.log("(empty tree)");
            return;
        }
        
        this._visualize(this.root, "", true);
        
        console.log("─".repeat(60));
        console.log(`Height: ${this.getHeight(this.root)}`);
        console.log(`Rotations performed: ${this.rotationCount}`);
        console.log(`Is Valid AVL: ${this.isValidAVL()}`);
        console.log("═".repeat(60) + "\n");
    }
    
    _visualize(node, prefix, isLast) {
        if (node !== null) {
            const bf = this.getBalanceFactor(node);
            const bfSymbol = bf > 0 ? `+${bf}` : `${bf}`;
            
            console.log(
                prefix + 
                (isLast ? "└── " : "├── ") + 
                `${node.key} (h=${node.height}, bf=${bfSymbol})`
            );
            
            const newPrefix = prefix + (isLast ? "    " : "│   ");
            
            // Print both children (or indicate null)
            if (node.left || node.right) {
                if (node.left) {
                    this._visualize(node.left, newPrefix, !node.right);
                } else {
                    console.log(newPrefix + "├── (null)");
                }
                
                if (node.right) {
                    this._visualize(node.right, newPrefix, true);
                } else if (node.left) {
                    console.log(newPrefix + "└── (null)");
                }
            }
        }
    }
}
```
