## 📖 Formal Definition

> **An Array is a collection of elements stored at contiguous (side-by-side) memory locations, accessible using an index (room number).**

# Chapter 3: How Arrays Work in Memory

## 🎬 Animation: Memory Layout

Imagine computer memory as a **long street of houses**:

```
MEMORY (Think of it as a street with addresses)
═══════════════════════════════════════════════════════════

Address:   1000    1004    1008    1012    1016    1020
            │       │       │       │       │       │
            ▼       ▼       ▼       ▼       ▼       ▼
        ┌───────┬───────┬───────┬───────┬───────┬───────┐
        │  85   │  90   │  78   │  92   │   88  │       │
        └───────┴───────┴───────┴───────┴───────┴───────┘
            ▲       ▲       ▲       ▲       ▲
            │       │       │       │       │

     marks[0] marks[1] marks[2] marks[3] marks[4]

  Index:    0       1       2       3       4
```

### 🔑 Why Does Indexing Start at 0?

```
Index = OFFSET from the starting position

┌─────────────────────────────────────────────────────────┐
│                                                         │
│  marks[0] → Start + 0 steps = First element             │
│  marks[1] → Start + 1 step  = Second element            │
│  marks[2] → Start + 2 steps = Third element             │
│                                                         │
│  Formula: Address = BaseAddress + (Index × ElementSize) │
│                                                         │
│  For marks[2]: 1000 + (2 × 4 bytes) = 1008 ✓            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**That's why index starts at 0 — it represents the OFFSET!**

# Chapter 4: Creating Arrays in JavaScript

## 🛠️ Method 1: Array Literal (Most Common)

```javascript
// Empty array
let emptyArray = [];

// Array with values
let fruits = ["Apple", "Banana", "Mango"];
let numbers = [10, 20, 30, 40, 50];
let mixed = [1, "Hello", true, null, { name: "John" }];

console.log(fruits); // ["Apple", "Banana", "Mango"]
console.log(numbers); // [10, 20, 30, 40, 50]
```

**Visualization:**

```
fruits Array:
┌───────────┬───────────┬───────────┐
│  "Apple"  │ "Banana"  │  "Mango"  │
└───────────┴───────────┴───────────┘
   Index 0     Index 1     Index 2

   fruits.length = 3
```

---

## 🛠️ Method 2: Array Constructor

```javascript
// Create empty array with size
let arr1 = new Array(5); // Creates [ , , , , ] (5 empty slots)

// Create array with values
let arr2 = new Array(1, 2, 3); // Creates [1, 2, 3]

console.log(arr1.length); // 5
console.log(arr2); // [1, 2, 3]
```

---

## 🛠️ Method 3: Array.from() — Creating from Other Things

```javascript
// From a string
let letters = Array.from("Hello");
console.log(letters); // ["H", "e", "l", "l", "o"]

// From a set
let mySet = new Set([1, 2, 3]);
let fromSet = Array.from(mySet);
console.log(fromSet); // [1, 2, 3]

// With a mapping function
let squares = Array.from([1, 2, 3, 4], (x) => x * x);
console.log(squares); // [1, 4, 9, 16]
```

---

## 🛠️ Method 4: Array.of() — Fixes Constructor Confusion

```javascript
// The problem with new Array():
let confusing = new Array(3); // Creates 3 empty slots, NOT [3]

// Array.of() solves this:
let clear = Array.of(3); // Creates [3]
let multiple = Array.of(1, 2, 3); // Creates [1, 2, 3]

console.log(clear); // [3]
console.log(multiple); // [1, 2, 3]
```

```javascript
let matrix = [
```

```javascript
}

// Output:
// matrix[0][0] = 1
// matrix[0][1] = 2
// matrix[0][2] = 3
// matrix[1][0] = 4
// ... and so on
```

## 🔷 Type 3: Multi-Dimensional Array (3D and Beyond)

**Think of it as a Rubik's Cube!**

```
3D Array: Array of 2D Arrays (Layers of matrices)

                Layer 0          Layer 1
               ┌─────────┐      ┌─────────┐
              ╱│ 1  2  3 │     ╱│ 10 11 12│
             ╱ │ 4  5  6 │    ╱ │ 13 14 15│
            ╱  │ 7  8  9 │   ╱  │ 16 17 18│
           ┌───┴─────────┤  ┌───┴─────────┤
           │             │  │             │
           └─────────────┘  └─────────────┘

           Access: arr[layer][row][column]
           arr[0][1][2] = 6
           arr[1][0][1] = 11
```

### 💻 Code Example:

```javascript
// 3D Array - 2 layers, each with 2x3 matrix
let cube = [
  // Layer 0
  [
    [1, 2, 3],
    [4, 5, 6],
  ],
  // Layer 1
  [
    [7, 8, 9],
    [10, 11, 12],
  ],
];

console.log(cube[0]); // Layer 0: [[1,2,3], [4,5,6]]
console.log(cube[0][1]); // Row 1 of Layer 0: [4, 5, 6]
console.log(cube[0][1][2]); // Element: 6
console.log(cube[1][0][1]); // Element: 8

// Traversing 3D Array
for (let layer = 0; layer < cube.length; layer++) {
  console.log(`\n--- Layer ${layer} ---`);
  for (let row = 0; row < cube[layer].length; row++) {
    for (let col = 0; col < cube[layer][row].length; col++) {
      console.log(`cube[${layer}][${row}][${col}] = ${cube[layer][row][col]}`);
    }
  }
}
```

## 🔷 Type 4: Jagged Array (Ragged Array)

**Rows with DIFFERENT lengths — like stairs!**

```
Regular 2D Array:          Jagged Array:
┌─────┬─────┬─────┐        ┌─────┐
│  1  │  2  │  3  │        │  1  │
├─────┼─────┼─────┤        ├─────┼─────┼─────┐
│  4  │  5  │  6  │        │  2  │  3  │  4  │
├─────┼─────┼─────┤        ├─────┼─────┼─────┼─────┬─────┐
│  7  │  8  │  9  │        │  5  │  6  │  7  │  8  │  9  │
└─────┴─────┴─────┘        ├─────┼─────┤─────┴─────┴─────┘
                           │  10 │  11 │
All rows same length       └─────┴─────┘
                           Different row lengths!
```

### 💻 Code Example:

```javascript
// Jagged Array - rows have different lengths
let jagged = [
  [1], // 1 element
  [2, 3, 4], // 3 elements
  [5, 6, 7, 8, 9], // 5 elements
  [10, 11], // 2 elements
];

console.log(jagged[0].length); // 1
console.log(jagged[2].length); // 5
console.log(jagged[2][3]); // 8

// Traversing Jagged Array (careful with length!)
for (let i = 0; i < jagged.length; i++) {
  let row = "";
  for (let j = 0; j < jagged[i].length; j++) {
    row += jagged[i][j] + " ";
  }
  console.log(`Row ${i}: ${row}`);
}
// Output:
// Row 0: 1
// Row 1: 2 3 4
// Row 2: 5 6 7 8 9
// Row 3: 10 11
```

### 🌍 Real-World Use Case:

```javascript
// Students with different number of test scores
let studentScores = [
  [85, 90, 78], // Student 0: 3 tests
  [92, 88, 95, 91], // Student 1: 4 tests
  [76], // Student 2: 1 test
  [89, 94], // Student 3: 2 tests
];

// Calculate average for each student
for (let i = 0; i < studentScores.length; i++) {
  let sum = studentScores[i].reduce((a, b) => a + b, 0);
  let avg = sum / studentScores[i].length;
  console.log(`Student ${i}: ${avg.toFixed(2)}`);
}
```

## 🔷 Type 5: Dynamic Array (JavaScript's Superpower!)

**In JavaScript, ALL arrays are dynamic — they grow and shrink automatically!**

```
STATIC ARRAY (C, Java):          DYNAMIC ARRAY (JavaScript):
┌─────┬─────┬─────┬─────┐        ┌─────┬─────┐
│  1  │  2  │  3  │     │        │  1  │  2  │  ← Start small
└─────┴─────┴─────┴─────┘        └─────┴─────┘
    Size fixed at creation!             ↓
    Can't add more elements!      ┌─────┬─────┬─────┬─────┐
                                  │  1  │  2  │  3  │  4  │  ← Grows!
                                  └─────┴─────┴─────┴─────┘
                                        ↓
                                  ┌─────┬─────┐
                                  │  1  │  2  │  ← Shrinks!
                                  └─────┴─────┘
```

### 💻 Code Example:

```javascript
let dynamic = []; // Start empty
console.log(dynamic.length); // 0

dynamic.push(10); // Add element
dynamic.push(20);
dynamic.push(30);
console.log(dynamic); // [10, 20, 30]
console.log(dynamic.length); // 3

dynamic.pop(); // Remove last
console.log(dynamic); // [10, 20]
console.log(dynamic.length); // 2

// Direct index assignment (creates holes!)
dynamic[10] = 100;
console.log(dynamic); // [10, 20, <8 empty items>, 100]
console.log(dynamic.length); // 11 (!)
```

```javascript
let fruits = ["Apple", "Banana", "Mango", "Orange"];
```

```javascript
console.log("--- For Loop ---");
```

```javascript
console.log("--- forEach Method ---");
```

## 📌 Operation 2: INSERTION

### 🔹 Insert at END — push() ⏱️ O(1)

```javascript
let arr = [10, 20, 30];

// Animation:
// Before: [10, 20, 30, ___]
//                       ↑
//                    insert 40
// After:  [10, 20, 30, 40]

arr.push(40);
console.log(arr); // [10, 20, 30, 40]

// Push multiple
arr.push(50, 60);
console.log(arr); // [10, 20, 30, 40, 50, 60]
```

### 🔹 Insert at BEGINNING — unshift() ⏱️ O(n)

```javascript
let arr = [20, 30, 40];

// Animation:
// Before: [20, 30, 40]
//          ↓   ↓   ↓      Shift everything right!
// After:  [10, 20, 30, 40]
//          ↑
//       insert 10

arr.unshift(10);
console.log(arr); // [10, 20, 30, 40]

// Unshift multiple
arr.unshift(0, 5);
console.log(arr); // [0, 5, 10, 20, 30, 40]
```

### 🔹 Insert at ANY POSITION — splice() ⏱️ O(n)

```javascript
let arr = [10, 20, 40, 50];

// Insert 30 at index 2
//
// Before: [10, 20, 40, 50]
//                ↑
//          insert 30 here
//
// After:  [10, 20, 30, 40, 50]

arr.splice(2, 0, 30); // At index 2, delete 0, insert 30
console.log(arr); // [10, 20, 30, 40, 50]

// Insert multiple elements
arr.splice(3, 0, 35, 37);
console.log(arr); // [10, 20, 30, 35, 37, 40, 50]
```

**splice() Syntax Breakdown:**

```
array.splice(startIndex, deleteCount, item1, item2, ...)
              ↓            ↓           ↓
         Where to     How many    What to
         start        to remove   insert
```

## 📌 Operation 3: DELETION

### 🔹 Delete from END — pop() ⏱️ O(1)

```javascript
let arr = [10, 20, 30, 40];

// Animation:
// Before: [10, 20, 30, 40]
//                       ↑
//                    remove
// After:  [10, 20, 30]

let removed = arr.pop();
console.log(removed); // 40
console.log(arr); // [10, 20, 30]
```

### 🔹 Delete from BEGINNING — shift() ⏱️ O(n)

```javascript
let arr = [10, 20, 30, 40];

// Animation:
// Before: [10, 20, 30, 40]
//          ↑
//       remove
// After:  [20, 30, 40]
//          ←   ←   ←     Everything shifts left!

let removed = arr.shift();
console.log(removed); // 10
console.log(arr); // [20, 30, 40]
```

### 🔹 Delete from ANY POSITION — splice() ⏱️ O(n)

```javascript
let arr = [10, 20, 30, 40, 50];

// Delete 1 element at index 2 (which is 30)
//
// Before: [10, 20, 30, 40, 50]
//                ↑
//             delete
// After:  [10, 20, 40, 50]

let removed = arr.splice(2, 1);
console.log(removed); // [30]
console.log(arr); // [10, 20, 40, 50]

// Delete multiple elements
let removed2 = arr.splice(1, 2); // Delete 2 elements from index 1
console.log(removed2); // [20, 40]
console.log(arr); // [10, 50]
```

### 🔹 Delete by VALUE — filter() ⏱️ O(n)

```javascript
let arr = [10, 20, 30, 20, 40, 20];

// Remove all 20s
let filtered = arr.filter((x) => x !== 20);
console.log(filtered); // [10, 30, 40]
console.log(arr); // [10, 20, 30, 20, 40, 20] (original unchanged!)
```

## 📌 Operation 4: SEARCHING

### 🔹 Linear Search ⏱️ O(n)

**Check every element one by one**

```javascript
function linearSearch(arr, target) {
```

### 🔹 Binary Search ⏱️ O(log n)

**ONLY works on SORTED arrays! Divide and conquer approach.**

```javascript
function binarySearch(arr, target) {
  let left = 0;
  let right = arr.length - 1;

  while (left <= right) {
    let mid = Math.floor((left + right) / 2);

    if (arr[mid] === target) {
      return mid; // Found!
    } else if (arr[mid] < target) {
      left = mid + 1; // Search right half
    } else {
      right = mid - 1; // Search left half
    }
  }

  return -1; // Not found
}

let sorted = [10, 20, 30, 40, 50, 60, 70, 80, 90];
console.log(binarySearch(sorted, 50)); // 4
console.log(binarySearch(sorted, 35)); // -1
```

**Animation: Finding 50**

```
        0   1   2   3   4   5   6   7   8

Step 1: left=0, right=8, mid=4
        [10, 20, 30, 40, 👁️50, 60, 70, 80, 90]
```

### 🔹 Bubble Sort (Interview Classic) ⏱️ O(n²)

```javascript
function bubbleSort(arr) {
  let n = arr.length;

  for (let i = 0; i < n - 1; i++) {
    for (let j = 0; j < n - i - 1; j++) {
      if (arr[j] > arr[j + 1]) {
        // Swap
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
      }
    }
  }

  return arr;
}

console.log(bubbleSort([64, 34, 25, 12, 22, 11, 90]));
// [11, 12, 22, 25, 34, 64, 90]
```

**Animation:**

```
[64, 34, 25, 12, 22, 11, 90]

Pass 1: Compare adjacent, swap if wrong order
        64 > 34 → swap → [34, 64, 25, 12, 22, 11, 90]
        64 > 25 → swap → [34, 25, 64, 12, 22, 11, 90]
        64 > 12 → swap → [34, 25, 12, 64, 22, 11, 90]
        64 > 22 → swap → [34, 25, 12, 22, 64, 11, 90]
        64 > 11 → swap → [34, 25, 12, 22, 11, 64, 90]
        64 < 90 → no swap
        Result: [34, 25, 12, 22, 11, 64, 90]
        90 is now at correct position! 🎯

Pass 2: (repeat for remaining elements)
        ...and so on
```

```javascript
function findMinMax(arr) {
  if (arr.length === 0) return null;

  let min = arr[0];
```

```javascript
function secondLargest(arr) {
  if (arr.length < 2) return null;

  let first = -Infinity;
  let second = -Infinity;

  for (let num of arr) {
    if (num > first) {
      second = first;
      first = num;
    } else if (num > second && num !== first) {
      second = num;
    }
  }

  return second === -Infinity ? null : second;
}
```

```javascript
function twoSum(arr, target) {
  let map = new Map();

  for (let i = 0; i < arr.length; i++) {
    let complement = target - arr[i];

    if (map.has(complement)) {
      return [map.get(complement), i];
    }

    map.set(arr[i], i);
  }

  return [];
}

console.log(twoSum([2, 7, 11, 15], 9)); // [0, 1] (2 + 7 = 9)
```

```javascript
function moveZeros(arr) {
  let insertPos = 0;

  // Move non-zeros to front
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] !== 0) {
      arr[insertPos] = arr[i];
      insertPos++;
    }
  }

  // Fill remaining with zeros
  while (insertPos < arr.length) {
    arr[insertPos] = 0;
    insertPos++;
  }

  return arr;
}
```
