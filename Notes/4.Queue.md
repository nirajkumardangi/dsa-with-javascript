# Understanding Queues: From Everyday Lines to Code

## 🎬 The Opening Scene: A Coffee Shop Line

Picture this: It's Monday morning. You walk into your favorite coffee shop, and there's a line of people waiting. You join at the **back**. The barista serves the person at the **front**. When that person leaves, the next person moves up.

This is a **Queue**.

```
    ☕ COUNTER
    ═══════════

    👤 ← Person being served (FRONT)
    👤
    👤
    👤 ← You just joined (BACK)
```

The rule is simple and fair: **First person to arrive = First person served.**

---

## 🧠 The Core Principle: FIFO

This pattern has a name in computer science:

```
╔═══════════════════════════════════════════════════════╗
║       F    I    F    O                                ║
║     First In, First Out                               ║
╚═══════════════════════════════════════════════════════╝
```

Think of it like a **tunnel**:

```
                    ┌─────────────────────────────────┐
   Items enter  →→→ │  ●    ●    ●    ●    ●    ●     │ →→→  Items exit
     (REAR)         └─────────────────────────────────┘        (FRONT)
```

Whatever goes in first, comes out first. There's no cutting in line!

---

## 🤔 Why Does This Exist? The Problem It Solves

Imagine you're building a **printer system**. Three people send print jobs:

```
1st: Alice sends a 10-page document
2nd: Bob sends a 2-page document
3rd: Carol sends a 5-page document
```

Without a queue, chaos! The printer might randomly pick Bob's job first, making Alice wait even though she was first.

**With a queue**: Jobs process in order → Fair, predictable, organized.

### Real-World Uses:

- 🖨️ Print job scheduling
- 📞 Call center hold lines
- 🎮 Matchmaking in online games
- 🌐 Web server handling requests
- 🗺️ GPS finding shortest paths (BFS algorithm)

---

## 🎯 The Essential Operations

A queue needs just a few core abilities:

```
╔════════════════════════════════════════════════════════════════╗
║  OPERATION    │  WHAT IT DOES              │  COFFEE ANALOGY   ║
╠════════════════════════════════════════════════════════════════╣
║  enqueue()    │  Add item to BACK          │  Join the line    ║
║  dequeue()    │  Remove item from FRONT    │  Get served       ║
║  peek()       │  Look at FRONT item        │  Who's next?      ║
║  isEmpty()    │  Check if queue is empty   │  Anyone waiting?  ║
║  size()       │  Count items in queue      │  How long is it?  ║
╚════════════════════════════════════════════════════════════════╝
```

# 📦 Implementation #1: Array-Based Queue

Let's build a queue using the simplest tool: an array.

## The Naive Approach (Simple but Slow)

Imagine boxes in a row:

```
STEP 1: Empty queue
┌─────────────────────────────────────┐
│                                     │
└─────────────────────────────────────┘
  FRONT                          BACK

STEP 2: enqueue("Alice")
┌─────────────────────────────────────┐
│  Alice                              │
└─────────────────────────────────────┘
  FRONT/BACK

STEP 3: enqueue("Bob")
┌─────────────────────────────────────┐
│  Alice  │  Bob                      │
└─────────────────────────────────────┘
  FRONT       BACK

STEP 4: enqueue("Carol")
┌─────────────────────────────────────┐
│  Alice  │  Bob   │  Carol           │
└─────────────────────────────────────┘
  FRONT                BACK

STEP 5: dequeue() → Returns "Alice"
┌─────────────────────────────────────┐
│  Bob   │  Carol                     │  ← Everyone shifted left!
└─────────────────────────────────────┘
  FRONT      BACK
```

### The Code (Simple Version):

```javascript
class SimpleArrayQueue {
  constructor() {
    this.items = [];
  }

  // Add to the back
  enqueue(element) {
    this.items.push(element);
  }

  // Remove from the front
  dequeue() {
    if (this.isEmpty()) {
      return "Queue is empty!";
    }
    return this.items.shift(); // ⚠️ Problem here!
  }

  // Look at the front
  peek() {
    if (this.isEmpty()) {
      return "Queue is empty!";
    }
    return this.items[0];
  }

  isEmpty() {
    return this.items.length === 0;
  }

  size() {
    return this.items.length;
  }

  // Visualize the queue
  print() {
    console.log("FRONT →", this.items.join(" → "), "← BACK");
  }
}

// Let's test it!
const coffeeShop = new SimpleArrayQueue();

coffeeShop.enqueue("Alice");
coffeeShop.enqueue("Bob");
coffeeShop.enqueue("Carol");
coffeeShop.print(); // FRONT → Alice → Bob → Carol ← BACK

console.log(coffeeShop.dequeue()); // Alice
coffeeShop.print(); // FRONT → Bob → Carol ← BACK

console.log(coffeeShop.peek()); // Bob
```

## ⚠️ The Hidden Problem with `shift()`

Here's something crucial that isn't obvious:

```
When we call shift() to remove the first element...

BEFORE shift():
┌───────┬───────┬───────┬───────┬───────┐
│   A   │   B   │   C   │   D   │   E   │
└───────┴───────┴───────┴───────┴───────┘
  [0]     [1]     [2]     [3]     [4]

AFTER shift():
┌───────┬───────┬───────┬───────┬───────┐
│   B   │   C   │   D   │   E   │       │
└───────┴───────┴───────┴───────┴───────┘
  [0]     [1]     [2]     [3]

Every single element had to MOVE one position left!
```

If you have 1 million items, removing one item requires moving 999,999 items!

**Time Complexity:**

- `enqueue()` → O(1) ✓ Fast
- `dequeue()` → O(n) ✗ Slow!

## 🚀 The Optimized Array Queue (Using Pointers)

Instead of actually moving elements, we use **pointers** to track the front and back:

```
Initial state with front and rear pointers:

Index:    0       1       2       3       4
       ┌───────┬───────┬───────┬───────┬───────┐
       │ Alice │  Bob  │ Carol │       │       │
       └───────┴───────┴───────┴───────┴───────┘
          ↑                       ↑
        front                   rear

After dequeue() - just move the pointer!

Index:    0       1       2       3       4
       ┌───────┬───────┬───────┬───────┬───────┐
       │(Alice)│  Bob  │ Carol │       │       │
       └───────┴───────┴───────┴───────┴───────┘
                  ↑               ↑
                front           rear

Alice is still there in memory, but we ignore it!
```

### The Optimized Code:

```javascript
class OptimizedArrayQueue {
  constructor() {
    this.items = {}; // Using object as storage
    this.frontIndex = 0; // Points to front element
    this.rearIndex = 0; // Points to next empty slot
  }

  // Add to the back - O(1)
  enqueue(element) {
    this.items[this.rearIndex] = element;
    this.rearIndex++;
  }

  // Remove from front - O(1) now!
  dequeue() {
    if (this.isEmpty()) {
      return "Queue is empty!";
    }

    const removedItem = this.items[this.frontIndex];
    delete this.items[this.frontIndex]; // Clean up memory
    this.frontIndex++;
    return removedItem;
  }

  peek() {
    if (this.isEmpty()) {
      return "Queue is empty!";
    }
    return this.items[this.frontIndex];
  }

  isEmpty() {
    return this.rearIndex === this.frontIndex;
  }

  size() {
    return this.rearIndex - this.frontIndex;
  }

  print() {
    const elements = [];
    for (let i = this.frontIndex; i < this.rearIndex; i++) {
      elements.push(this.items[i]);
    }
    console.log("FRONT →", elements.join(" → "), "← BACK");
  }
}

// Test it!
const fastQueue = new OptimizedArrayQueue();

fastQueue.enqueue("Task 1");
fastQueue.enqueue("Task 2");
fastQueue.enqueue("Task 3");
fastQueue.print(); // FRONT → Task 1 → Task 2 → Task 3 ← BACK

console.log("Processing:", fastQueue.dequeue()); // Task 1
console.log("Processing:", fastQueue.dequeue()); // Task 2
fastQueue.print(); // FRONT → Task 3 ← BACK

console.log("Queue size:", fastQueue.size()); // 1
```

Now both operations are O(1)! 🎉

# 🔗 Implementation #2: Linked List Queue

Think of a linked list as **train cars connected by couplings**:

```
  ┌─────────┐     ┌─────────┐     ┌─────────┐
  │  Alice  │────→│   Bob   │────→│  Carol  │────→ null
  └─────────┘     └─────────┘     └─────────┘
       ↑                               ↑
     HEAD                            TAIL
    (FRONT)                         (BACK)
```

Each "car" (node) contains:

1. The **data** (person's name)
2. A **pointer** to the next car

---

## 🎨 Visualizing Linked List Operations

### Enqueue (Add to back):

```
BEFORE: Add "David" to the queue

  ┌─────────┐     ┌─────────┐     ┌─────────┐
  │  Alice  │────→│   Bob   │────→│  Carol  │────→ null
  └─────────┘     └─────────┘     └─────────┘
      HEAD                            TAIL

STEP 1: Create new node

  ┌─────────┐
  │  David  │────→ null
  └─────────┘
     (new)

STEP 2: Connect Carol to David

  ┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
  │  Alice  │────→│   Bob   │────→│  Carol  │────→│  David  │────→ null
  └─────────┘     └─────────┘     └─────────┘     └─────────┘
      HEAD                                            TAIL
                                                 (moved here)
```

### Dequeue (Remove from front):

```
BEFORE: Remove Alice

  ┌─────────┐     ┌─────────┐     ┌─────────┐
  │  Alice  │────→│   Bob   │────→│  Carol  │────→ null
  └─────────┘     └─────────┘     └─────────┘
      HEAD                            TAIL

AFTER: Just move head pointer!

               ┌─────────┐     ┌─────────┐
               │   Bob   │────→│  Carol  │────→ null
               └─────────┘     └─────────┘
                  HEAD             TAIL

  ┌─────────┐
  │  Alice  │  → (garbage collected / freed)
  └─────────┘
```

## The Complete Linked List Queue Code:

```javascript
// First, we define what a "train car" (node) looks like
class Node {
  constructor(data) {
    this.data = data; // The actual value
    this.next = null; // Pointer to next node
  }
}

class LinkedListQueue {
  constructor() {
    this.head = null; // Front of queue
    this.tail = null; // Back of queue
    this.length = 0; // Track size
  }

  // Add to the back - O(1)
  enqueue(data) {
    const newNode = new Node(data);

    if (this.isEmpty()) {
      // First node! It's both head and tail
      this.head = newNode;
      this.tail = newNode;
    } else {
      // Link current tail to new node
      this.tail.next = newNode;
      // Move tail pointer to new node
      this.tail = newNode;
    }

    this.length++;
  }

  // Remove from front - O(1)
  dequeue() {
    if (this.isEmpty()) {
      return "Queue is empty!";
    }

    // Save the data to return
    const removedData = this.head.data;

    // Move head to next node
    this.head = this.head.next;
    this.length--;

    // If queue is now empty, reset tail too
    if (this.isEmpty()) {
      this.tail = null;
    }

    return removedData;
  }

  // Look at front element - O(1)
  peek() {
    if (this.isEmpty()) {
      return "Queue is empty!";
    }
    return this.head.data;
  }

  isEmpty() {
    return this.length === 0;
  }

  size() {
    return this.length;
  }

  // Visual representation
  print() {
    if (this.isEmpty()) {
      console.log("Queue is empty");
      return;
    }

    let result = "FRONT → ";
    let current = this.head;

    while (current !== null) {
      result += `[${current.data}]`;
      if (current.next !== null) {
        result += " → ";
      }
      current = current.next;
    }

    result += " ← BACK";
    console.log(result);
  }

  // Fancy visual with boxes
  visualize() {
    if (this.isEmpty()) {
      console.log("Empty Queue: HEAD → null ← TAIL");
      return;
    }

    let boxes = "";
    let arrows = "";
    let current = this.head;

    while (current !== null) {
      boxes += `┌─────────┐   `;
      current = current.next;
    }
    console.log(boxes);

    current = this.head;
    while (current !== null) {
      const data = current.data.toString().padStart(4).padEnd(7);
      if (current.next !== null) {
        process.stdout.write(`│${data}│──→`);
      } else {
        process.stdout.write(`│${data}│──→ null`);
      }
      current = current.next;
    }
    console.log();

    current = this.head;
    while (current !== null) {
      boxes = `└─────────┘   `;
      process.stdout.write(boxes);
      current = current.next;
    }
    console.log();
  }
}

// Let's see it in action!
console.log("=== LINKED LIST QUEUE DEMO ===\n");

const printQueue = new LinkedListQueue();

console.log("Adding print jobs to queue...\n");

printQueue.enqueue("Report.pdf");
printQueue.enqueue("Photo.jpg");
printQueue.enqueue("Essay.docx");

printQueue.print();
// FRONT → [Report.pdf] → [Photo.jpg] → [Essay.docx] ← BACK

console.log("\nPrinting (dequeue):", printQueue.dequeue());
// Printing (dequeue): Report.pdf

printQueue.print();
// FRONT → [Photo.jpg] → [Essay.docx] ← BACK

console.log("\nNext in queue (peek):", printQueue.peek());
// Next in queue (peek): Photo.jpg

console.log("Queue size:", printQueue.size());
// Queue size: 2

printQueue.enqueue("Invoice.pdf");
console.log("\nAfter adding Invoice.pdf:");
printQueue.print();
// FRONT → [Photo.jpg] → [Essay.docx] → [Invoice.pdf] ← BACK
```

# ⚖️ Array vs Linked List: The Showdown

```
╔══════════════════════════════════════════════════════════════════════╗
║  OPERATION     │   SIMPLE ARRAY   │  OPTIMIZED ARRAY  │  LINKED LIST ║
╠══════════════════════════════════════════════════════════════════════╣
║  enqueue()     │      O(1)        │       O(1)        │     O(1)     ║
║  dequeue()     │      O(n) ✗      │       O(1)        │     O(1)     ║
║  peek()        │      O(1)        │       O(1)        │     O(1)     ║
║  isEmpty()     │      O(1)        │       O(1)        │     O(1)     ║
╠══════════════════════════════════════════════════════════════════════╣
║  MEMORY        │   Contiguous     │    Contiguous     │   Scattered  ║
║  OVERHEAD      │      Low         │       Low         │   High*      ║
║  CACHE         │    Friendly      │     Friendly      │  Unfriendly  ║
╚══════════════════════════════════════════════════════════════════════╝

* Each node needs extra memory for the "next" pointer
```

### When to Use Which?

```
📦 ARRAY (Optimized):
   ✓ You know approximate maximum size
   ✓ Memory efficiency matters
   ✓ Mostly static operations

🔗 LINKED LIST:
   ✓ Size is completely unpredictable
   ✓ Very frequent add/remove operations
   ✓ You're implementing in a language without dynamic arrays
```

# 🎮 Complete Example: Task Scheduler

Let's build something practical - a task scheduler using both implementations:

```javascript
// Using our LinkedListQueue from above
class TaskScheduler {
  constructor() {
    this.taskQueue = new LinkedListQueue();
    this.completedTasks = [];
  }

  addTask(taskName, priority = "normal") {
    const task = {
      name: taskName,
      priority: priority,
      addedAt: new Date().toLocaleTimeString(),
    };
    this.taskQueue.enqueue(task);
    console.log(`📥 Added: "${taskName}" (${priority}) at ${task.addedAt}`);
  }

  processNextTask() {
    if (this.taskQueue.isEmpty()) {
      console.log("📭 No tasks to process!");
      return null;
    }

    const task = this.taskQueue.dequeue();
    this.completedTasks.push(task);
    console.log(`✅ Completed: "${task.name}"`);
    return task;
  }

  viewNextTask() {
    if (this.taskQueue.isEmpty()) {
      console.log("📭 Queue is empty");
      return null;
    }
    const next = this.taskQueue.peek();
    console.log(`👀 Next up: "${next.name}"`);
    return next;
  }

  processAllTasks() {
    console.log("\n🚀 Processing all tasks...\n");
    while (!this.taskQueue.isEmpty()) {
      this.processNextTask();
    }
    console.log("\n🎉 All tasks completed!");
  }

  getStatus() {
    console.log("\n📊 SCHEDULER STATUS:");
    console.log(`   Pending tasks: ${this.taskQueue.size()}`);
    console.log(`   Completed tasks: ${this.completedTasks.length}`);
  }
}

// Demo!
console.log("═══════════════════════════════════════");
console.log("         TASK SCHEDULER DEMO           ");
console.log("═══════════════════════════════════════\n");

const scheduler = new TaskScheduler();

scheduler.addTask("Reply to emails");
scheduler.addTask("Review PR #42");
scheduler.addTask("Update documentation");
scheduler.addTask("Fix login bug", "high");

scheduler.getStatus();

console.log("\n--- Processing some tasks ---\n");

scheduler.viewNextTask();
scheduler.processNextTask();
scheduler.processNextTask();

scheduler.getStatus();

console.log("\n--- Adding more tasks ---\n");

scheduler.addTask("Deploy to staging");

scheduler.processAllTasks();
scheduler.getStatus();
```

                    ║                                   ║
