## 📖 Formal Definition

> **A Stack is a linear data structure that follows the LIFO (Last In, First Out) principle. Elements can only be added or removed from one end, called the TOP.**

```
┌──────────────────────────────────────────────────────────────┐
│                    STACK PROPERTIES                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
```

```
║                    ADT = Abstract Data Type                       ║
╠═══════════════════════════════════════════════════════════════════╣
║                                                                   ║
║   An ADT defines WHAT operations can be performed,                ║
║   but NOT HOW they are implemented.                               ║
║                                                                   ║
║   Think of it like a TV remote:                                   ║
║   • You know WHAT buttons do (power, volume, channel)             ║
║   • You don't need to know HOW it works internally                ║
║                                                                   ║
║   ┌─────────────────────────────────────────────────────────┐     ║
║   │                    STACK ADT                            │     ║
║   ├─────────────────────────────────────────────────────────┤     ║
```

# Chapter 3: Array Implementation of Stack

## 🏗️ The Concept

```
╔═══════════════════════════════════════════════════════════════════╗
║              ARRAY-BASED STACK IMPLEMENTATION                     ║
╠═══════════════════════════════════════════════════════════════════╣
║                                                                   ║
║   Use an array and a "top" pointer to track the top element       ║
║                                                                   ║
║   Array:  ┌─────┬─────┬─────┬─────┬─────┬─────┐                   ║
║   Index:  │  0  │  1  │  2  │  3  │  4  │  5  │                   ║
║   Values: │ 10  │ 20  │ 30  │     │     │     │                   ║
║           └─────┴─────┴─────┴─────┴─────┴─────┘                   ║
║                          ↑                                        ║
║                         top = 2                                   ║
║                                                                   ║
║   • top = -1 means stack is empty                                 ║
║   • top = capacity - 1 means stack is full                        ║
║   • Push: increment top, then add element                         ║
║   • Pop: get element at top, then decrement top                   ║
║                                                                   ║
╚═══════════════════════════════════════════════════════════════════╝
```

---

## 💻 Complete Array Implementation

```javascript
// ═══════════════════════════════════════════════════════════════
//              STACK IMPLEMENTATION USING ARRAY
// ═══════════════════════════════════════════════════════════════

class StackArray {
  constructor(capacity = 10) {
    this.items = new Array(capacity); // Fixed-size array
    this.capacity = capacity; // Maximum size
    this.top = -1; // -1 means empty
  }

  // ─────────────────────────────────────────────────────────
  //                    CORE OPERATIONS
  // ─────────────────────────────────────────────────────────

  /**
   * PUSH - Add element to top of stack
   * Time Complexity: O(1)
   */
  push(element) {
    // Check for overflow
    if (this.isFull()) {
      console.log("Stack Overflow! Cannot push " + element);
      return false;
    }

    // Increment top and add element
    this.top++;
    this.items[this.top] = element;

    return true;
  }

  /**
   * POP - Remove and return top element
   * Time Complexity: O(1)
   */
  pop() {
    // Check for underflow
    if (this.isEmpty()) {
      console.log("Stack Underflow! Cannot pop from empty stack");
      return null;
    }

    // Get element and decrement top
    const poppedElement = this.items[this.top];
    this.items[this.top] = undefined; // Optional: clear the slot
    this.top--;

    return poppedElement;
  }

  /**
   * PEEK - Return top element without removing
   * Time Complexity: O(1)
   */
  peek() {
    if (this.isEmpty()) {
      console.log("Stack is empty! Nothing to peek");
      return null;
    }

    return this.items[this.top];
  }

  // ─────────────────────────────────────────────────────────
  //                   UTILITY OPERATIONS
  // ─────────────────────────────────────────────────────────

  /**
   * isEmpty - Check if stack is empty
   * Time Complexity: O(1)
   */
  isEmpty() {
    return this.top === -1;
  }

  /**
   * isFull - Check if stack is full (for fixed-size)
   * Time Complexity: O(1)
   */
  isFull() {
    return this.top === this.capacity - 1;
  }

  /**
   * size - Return number of elements
   * Time Complexity: O(1)
   */
  size() {
    return this.top + 1;
  }

  /**
   * clear - Remove all elements
   * Time Complexity: O(1) or O(n) depending on implementation
   */
  clear() {
    this.items = new Array(this.capacity);
    this.top = -1;
  }

  /**
   * print - Display stack contents
   * Time Complexity: O(n)
   */
  print() {
    if (this.isEmpty()) {
      console.log("Stack is empty");
      return;
    }

    console.log("Stack (top → bottom):");
    for (let i = this.top; i >= 0; i--) {
      const marker = i === this.top ? " ← top" : "";
      console.log(`  [${i}]: ${this.items[i]}${marker}`);
    }
  }

  /**
   * toArray - Convert stack to array
   * Time Complexity: O(n)
   */
  toArray() {
    return this.items.slice(0, this.top + 1);
  }
}
```

## 💻 Using the Array Stack

```javascript
// Create a stack with capacity 5
const stack = new StackArray(5);

// Push elements
console.log("Pushing elements...");
stack.push(10);
stack.push(20);
stack.push(30);
stack.print();
/*
Stack (top → bottom):
  [2]: 30 ← top
  [1]: 20
  [0]: 10
*/

// Peek at top
console.log("Peek:", stack.peek()); // 30

// Pop elements
console.log("Popped:", stack.pop()); // 30
console.log("Popped:", stack.pop()); // 20

stack.print();
/*
Stack (top → bottom):
  [0]: 10 ← top
*/

// Check status
console.log("Size:", stack.size()); // 1
console.log("Is Empty:", stack.isEmpty()); // false
console.log("Is Full:", stack.isFull()); // false
```

# Chapter 4: Dynamic Array Implementation

## 🔄 Auto-Resizing Stack

```javascript
// ═══════════════════════════════════════════════════════════════
//         DYNAMIC STACK USING JAVASCRIPT ARRAY (Auto-resize)
// ═══════════════════════════════════════════════════════════════

class DynamicStack {
  constructor() {
    this.items = []; // JavaScript arrays are dynamic!
  }

  // PUSH - O(1) amortized
  push(element) {
    this.items.push(element);
  }

  // POP - O(1)
  pop() {
    if (this.isEmpty()) {
      console.log("Stack Underflow!");
      return null;
    }
    return this.items.pop();
  }

  // PEEK - O(1)
  peek() {
    if (this.isEmpty()) {
      return null;
    }
    return this.items[this.items.length - 1];
  }

  // isEmpty - O(1)
  isEmpty() {
    return this.items.length === 0;
  }

  // size - O(1)
  size() {
    return this.items.length;
  }

  // clear - O(1)
  clear() {
    this.items = [];
  }

  // print - O(n)
  print() {
    if (this.isEmpty()) {
      console.log("Stack is empty");
      return;
    }
    console.log("Stack:", this.items.join(" → "), "← top");
  }
}

// Usage
const dynStack = new DynamicStack();
dynStack.push(1);
dynStack.push(2);
dynStack.push(3);
dynStack.print(); // Stack: 1 → 2 → 3 ← top
```

# Chapter 5: Linked List Implementation of Stack

## 🤔 Why Linked List?

```
║                  WHY USE LINKED LIST FOR STACK?                   ║
╠═══════════════════════════════════════════════════════════════════╣
║                                                                   ║
║   ARRAY PROBLEMS:                                                 ║
║   ───────────────                                                 ║
║   ❌ Fixed size (need to resize)                                  ║
║   ❌ Wasted space if not full                                     ║

║                                                                   ║
║   LINKED LIST ADVANTAGES:                                         ║
║   ────────────────────────                                        ║
║   ✅ Dynamic size (grows as needed)                               ║
║   ✅ No wasted space                                              ║
║   ✅ No overflow (until memory exhausted)                         ║
║   ✅ O(1) push and pop always                                     ║
║                                                                   ║
║   LINKED LIST DISADVANTAGES:                                      ║
║   ──────────────────────────                                      ║
║   ❌ Extra memory for pointers                                    ║
║   ❌ No cache locality (slower access)                            ║
║                                                                   ║
╚═══════════════════════════════════════════════════════════════════╝
```

## 🏗️ The Concept

```
╔═══════════════════════════════════════════════════════════════════╗
║             LINKED LIST BASED STACK IMPLEMENTATION                ║
╠═══════════════════════════════════════════════════════════════════╣
║                                                                   ║
║   Key Insight: Use the HEAD of linked list as the TOP of stack    ║
║                                                                   ║
║   Why HEAD = TOP?                                                 ║
║   • Insert at head = O(1) → Perfect for PUSH                      ║
║   • Delete from head = O(1) → Perfect for POP                     ║
║                                                                   ║
║   Stack View:              Linked List View:                      ║
║                                                                   ║
║      ┌────┐                HEAD/TOP                               ║
║      │ 30 │ ← top            │                                    ║
║      ├────┤                  ▼                                    ║
║      │ 20 │              ┌───────┐   ┌───────┐   ┌───────┐        ║
║      ├────┤              │ 30    │──>│ 20    │──>│ 10    │──>null ║
║      │ 10 │              └───────┘   └───────┘   └───────┘        ║
║      └────┘                 top                     bottom        ║
║                                                                   ║
║   PUSH: Insert new node at head                                   ║
║   POP:  Remove node from head                                     ║
║                                                                   ║
╚═══════════════════════════════════════════════════════════════════╝
```

## 💻 Complete Linked List Implementation

```javascript
// ═══════════════════════════════════════════════════════════════
//                        NODE CLASS
// ═══════════════════════════════════════════════════════════════

class Node {
  constructor(data) {
    this.data = data;
    this.next = null;
  }
}

// ═══════════════════════════════════════════════════════════════
//            STACK IMPLEMENTATION USING LINKED LIST
// ═══════════════════════════════════════════════════════════════

class StackLinkedList {
  constructor() {
    this.top = null; // Head of linked list = Top of stack
    this.length = 0; // Track size
  }

  // ─────────────────────────────────────────────────────────
  //                    CORE OPERATIONS
  // ─────────────────────────────────────────────────────────

  /**
   * PUSH - Add element to top of stack
   * Time Complexity: O(1)
   *
   * Same as inserting at HEAD of linked list
   */
  push(element) {
    const newNode = new Node(element);

    // Point new node to current top
    newNode.next = this.top;

    // New node becomes the top
    this.top = newNode;

    this.length++;

    return this; // For chaining
  }

  /**
   * POP - Remove and return top element
   * Time Complexity: O(1)
   *
   * Same as deleting HEAD of linked list
   */
  pop() {
    // Check for underflow
    if (this.isEmpty()) {
      console.log("Stack Underflow! Cannot pop from empty stack");
      return null;
    }

    // Get the top element
    const poppedNode = this.top;

    // Move top to next node
    this.top = this.top.next;

    // Clear the next pointer of removed node
    poppedNode.next = null;

    this.length--;

    return poppedNode.data;
  }

  /**
   * PEEK - Return top element without removing
   * Time Complexity: O(1)
   */
  peek() {
    if (this.isEmpty()) {
      console.log("Stack is empty! Nothing to peek");
      return null;
    }

    return this.top.data;
  }

  // ─────────────────────────────────────────────────────────
  //                   UTILITY OPERATIONS
  // ─────────────────────────────────────────────────────────

  /**
   * isEmpty - Check if stack is empty
   * Time Complexity: O(1)
   */
  isEmpty() {
    return this.top === null;
    // OR: return this.length === 0;
  }

  /**
   * size - Return number of elements
   * Time Complexity: O(1)
   */
  size() {
    return this.length;
  }

  /**
   * clear - Remove all elements
   * Time Complexity: O(1)
   */
  clear() {
    this.top = null;
    this.length = 0;
  }

  /**
   * print - Display stack contents
   * Time Complexity: O(n)
   */
  print() {
    if (this.isEmpty()) {
      console.log("Stack is empty");
      return;
    }

    let current = this.top;
    let result = [];

    while (current !== null) {
      result.push(current.data);
      current = current.next;
    }

    console.log("Stack (top → bottom):");
    result.forEach((item, index) => {
      const marker = index === 0 ? " ← top" : "";
      console.log(`  ${item}${marker}`);
    });
  }

  /**
   * printAsLinkedList - Visual representation
   */
  printAsLinkedList() {
    if (this.isEmpty()) {
      console.log("top → null");
      return;
    }

    let current = this.top;
    let result = "top → ";

    while (current !== null) {
      result += `[${current.data}] → `;
      current = current.next;
    }

    result += "null";
    console.log(result);
  }

  /**
   * toArray - Convert stack to array
   * Time Complexity: O(n)
   */
  toArray() {
    let arr = [];
    let current = this.top;

    while (current !== null) {
      arr.push(current.data);
      current = current.next;
    }

    return arr;
  }

  /**
   * contains - Check if element exists
   * Time Complexity: O(n)
   */
  contains(element) {
    let current = this.top;

    while (current !== null) {
      if (current.data === element) {
        return true;
      }
      current = current.next;
    }

    return false;
  }
}
```

## 🎯 Problem 1: Valid Parentheses (LeetCode #20)

**Check if brackets are balanced: `()`, `[]`, `{}`**

```javascript
/**
 * Check if string has valid parentheses
 *
 * Examples:
 * "()" → true
 * "()[]{}" → true
 * "(]" → false
 * "([)]" → false
 * "{[]}" → true
 */
function isValidParentheses(s) {
  const stack = [];
  const pairs = {
    ")": "(",
    "]": "[",
    "}": "{",
  };

  for (let char of s) {
    if (char === "(" || char === "[" || char === "{") {
      // Opening bracket - push to stack
      stack.push(char);
    } else {
      // Closing bracket - check if matches
      if (stack.length === 0 || stack.pop() !== pairs[char]) {
        return false;
      }
    }
  }

  // Stack should be empty if all brackets matched
  return stack.length === 0;
}

console.log(isValidParentheses("([)]")); // false
console.log(isValidParentheses("{[]}")); // true
```

```javascript
/**
 * Evaluate postfix expression
 *
 * Example: ["2","1","+","3","*"] = ((2 + 1) * 3) = 9
 */
function evalRPN(tokens) {
  const stack = [];

  for (let token of tokens) {
    if (["+", "-", "*", "/"].includes(token)) {
      // Operator - pop two operands
      const b = stack.pop(); // Second operand
      const a = stack.pop(); // First operand

      let result;
      switch (token) {
        case "+":
          result = a + b;
          break;
        case "-":
          result = a - b;
          break;
        case "*":
          result = a * b;
          break;
        case "/":
          result = Math.trunc(a / b);
          break;
      }

      stack.push(result);
    } else {
      // Number - push to stack
      stack.push(parseInt(token));
    }
  }

  return stack.pop();
}

console.log(evalRPN(["4", "13", "5", "/", "+"])); // 6
```

## 🎯 Problem 3: Min Stack (LeetCode #155)

**Design a stack that supports getMin() in O(1) time**

```javascript
/**
 * Stack with O(1) minimum retrieval
 */
class MinStack {
  constructor() {
    this.stack = []; // Main stack
    this.minStack = []; // Tracks minimums
  }

  push(val) {
    this.stack.push(val);

    // Push to minStack if empty or val <= current min
    if (this.minStack.length === 0 || val <= this.getMin()) {
      this.minStack.push(val);
    }
  }

  pop() {
    const popped = this.stack.pop();

    // If popped element is the current min, pop from minStack too
    if (popped === this.getMin()) {
      this.minStack.pop();
    }

    return popped;
  }

  top() {
    return this.stack[this.stack.length - 1];
  }

  getMin() {
    return this.minStack[this.minStack.length - 1];
  }
}

console.log(minStack.getMin()); // -2
```

## 🎯 Problem 4: Implement Queue using Stacks

```javascript
/**
 * Implement Queue using two Stacks
 *
 * Key Insight: Reversing order twice gives original order!
 */
class QueueUsingStacks {
  constructor() {
    this.stack1 = []; // For enqueue
    this.stack2 = []; // For dequeue
  }

  // Add to queue - O(1)
  enqueue(x) {
    this.stack1.push(x);
  }

  // Remove from queue - Amortized O(1)
  dequeue() {
    // If stack2 is empty, transfer all from stack1
    if (this.stack2.length === 0) {
      while (this.stack1.length > 0) {
        this.stack2.push(this.stack1.pop());
      }
    }

    return this.stack2.pop();
  }

  // Peek front - Amortized O(1)
  peek() {
    if (this.stack2.length === 0) {
      while (this.stack1.length > 0) {
        this.stack2.push(this.stack1.pop());
      }
    }

    return this.stack2[this.stack2.length - 1];
  }

  isEmpty() {
    return this.stack1.length === 0 && this.stack2.length === 0;
  }
}

// Test

queue.enqueue(2);
queue.enqueue(3);

queue.enqueue(4);
console.log(queue.dequeue()); // 3
console.log(queue.dequeue()); // 4
```

```javascript
/**
 * For each element, find the next greater element to its right
 *
 * Example: [4, 5, 2, 25] → [5, 25, 25, -1]
 */
function nextGreaterElement(arr) {
  const n = arr.length;
  const result = new Array(n).fill(-1);
  const stack = []; // Stores indices

  for (let i = 0; i < n; i++) {
    // While stack is not empty and current element is greater
    // than element at index on top of stack
    while (stack.length > 0 && arr[i] > arr[stack[stack.length - 1]]) {
      const index = stack.pop();
      result[index] = arr[i];
    }

    stack.push(i);
  }

  return result;
}
```

## 🎯 Problem 6: Sort a Stack

```javascript
/**
 * Sort a stack using only another stack (no arrays)
 * Smallest element on top
 */
function sortStack(stack) {
  const tempStack = [];

  while (stack.length > 0) {
    // Pop from input stack
    const current = stack.pop();

    // Move elements from temp to input if they're greater than current
    while (tempStack.length > 0 && tempStack[tempStack.length - 1] > current) {
      stack.push(tempStack.pop());
    }

    // Push current to temp
    tempStack.push(current);
  }

  // Transfer back to original stack (reverse order)
  while (tempStack.length > 0) {
    stack.push(tempStack.pop());
  }

  return stack;
}

// Test

console.log(sortStack(stack)); // [3, 23, 31, 34, 92, 98]
```

```javascript
/**
 * Calculate stock span - number of consecutive days
 * before today where price was <= today's price
 *
 * Example: [100, 80, 60, 70, 60, 75, 85]
 * Spans:   [1,   1,  1,  2,  1,  4,  6]
 */
function stockSpan(prices) {
  const n = prices.length;
  const span = new Array(n);
  const stack = []; // Stores indices

  for (let i = 0; i < n; i++) {
    // Pop elements smaller than or equal to current
    while (stack.length > 0 && prices[stack[stack.length - 1]] <= prices[i]) {
      stack.pop();
    }

    // Calculate span
    span[i] = stack.length === 0 ? i + 1 : i - stack[stack.length - 1];

    // Push current index
    stack.push(i);
  }

  return span;
}
```

## 🎯 Problem 9: Infix to Postfix Conversion

```javascript
/**
 * Convert infix to postfix notation
 * Example: "a+b*c" → "abc*+"
 */
function infixToPostfix(expression) {
  const precedence = {
    "+": 1,
    "-": 1,
    "*": 2,
    "/": 2,
    "^": 3,
  };

  const stack = [];
  let result = "";

  for (let char of expression) {
    // If operand, add to result
    if (/[a-zA-Z0-9]/.test(char)) {
      result += char;
    }
    // If '(', push to stack
    else if (char === "(") {
      stack.push(char);
    }
    // If ')', pop until '('
    else if (char === ")") {
      while (stack.length > 0 && stack[stack.length - 1] !== "(") {
        result += stack.pop();
      }
      stack.pop(); // Remove '('
    }
    // If operator
    else if (precedence[char]) {
      while (
        stack.length > 0 &&
        stack[stack.length - 1] !== "(" &&
        precedence[stack[stack.length - 1]] >= precedence[char]
      ) {
        result += stack.pop();
      }
      stack.push(char);
    }
  }

  // Pop remaining operators
  while (stack.length > 0) {
    result += stack.pop();
  }

  return result;
}

// Test
console.log(infixToPostfix("a+b*c")); // "abc*+"
console.log(infixToPostfix("(a+b)*c")); // "ab+c*"
console.log(infixToPostfix("a+b*c-d/e")); // "abc*+de/-"
```

# Chapter 10: Quick Reference Card

```
╔═══════════════════════════════════════════════════════════════════╗
║                    STACK CHEAT SHEET                              ║
╠═══════════════════════════════════════════════════════════════════╣
║                                                                   ║
║  PRINCIPLE: LIFO (Last In, First Out)                             ║
║                                                                   ║
║  CORE OPERATIONS:                                                 ║
║  ─────────────────                                                ║
║  • push(x)    → Add element to top                                ║
║  • pop()      → Remove and return top                             ║
║  • peek()     → Return top without removing                       ║
║  • isEmpty()  → Check if stack is empty                           ║
║                                                                   ║
║  ARRAY IMPLEMENTATION:                                            ║
║  ──────────────────────                                           ║
║  • Use top pointer (-1 = empty)                                   ║
║  • push: top++, items[top] = x                                    ║
║  • pop:  return items[top--]                                      ║
║  • Check overflow: top === capacity - 1                           ║
║                                                                   ║
║  LINKED LIST IMPLEMENTATION:                                      ║
║  ────────────────────────────                                     ║
║  • Use head as top                                                ║
║  • push: Insert at head                                           ║
║  • pop:  Delete from head                                         ║
║  • No overflow (dynamic)                                          ║
║                                                                   ║
║  KEY APPLICATIONS:                                                ║
║  ─────────────────                                                ║
║  • Balanced parentheses                                           ║
║  • Function call stack                                            ║
║  • Undo/Redo operations                                           ║
║  • Expression evaluation                                          ║
║  • Backtracking algorithms                                        ║
║  • Browser history                                                ║
║                                                                   ║
║  INTERVIEW TIPS:                                                  ║
║  ───────────────                                                  ║
║  • Draw the stack state at each step                              ║
║  • Check for underflow (empty stack)                              ║
║  • Check for overflow (fixed array)                               ║
║  • Consider using stack for "nearest" problems                    ║
║  • Monotonic stack for next greater/smaller element               ║
║                                                                   ║
╚═══════════════════════════════════════════════════════════════════╝
```
