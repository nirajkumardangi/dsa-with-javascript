# 🔗 Linked Lists: The Complete Guide

# Chapter 1: The Problem with Arrays

## 🤔 Arrays Are Great, But...

Remember our hotel analogy for arrays? Every room is side by side, numbered sequentially.

```
ARRAY (Contiguous Memory):
┌──────┬──────┬──────┬──────┬──────┐
│  10  │  20  │  30  │  40  │  50  │
└──────┴──────┴──────┴──────┴──────┘
  1000   1004   1008   1012   1016

All rooms are CONNECTED, side by side.
```

### 😰 The Problems Begin...

**Problem 1: Insertion is Expensive!**

```
Insert 25 at position 2:

BEFORE: [10, 20, 30, 40, 50]
                ↑
           Insert 25 here

Step 1: Shift 30 → [10, 20, __, 30, 40, 50]
Step 2: Shift 40 → Already done above
Step 3: Shift 50 → Already done above
Step 4: Insert 25 → [10, 20, 25, 30, 40, 50]

We had to MOVE 3 elements! 😫
For 1 million elements? Move 999,998 elements!
```

**Problem 2: Deletion is Expensive Too!**

```
Delete 20 from position 1:

BEFORE: [10, 20, 30, 40, 50]
             ↑
          Delete this

Step 1: Remove 20 → [10, __, 30, 40, 50]
Step 2: Shift 30 ← [10, 30, __, 40, 50]
Step 3: Shift 40 ← [10, 30, 40, __, 50]
Step 4: Shift 50 ← [10, 30, 40, 50]

Again, shifting everyone! 😫
```

**Problem 3: Fixed Size (in some languages)**

```
Array created with size 5:
┌──────┬──────┬──────┬──────┬──────┐
│  10  │  20  │  30  │  40  │  50  │  FULL!
└──────┴──────┴──────┴──────┴──────┘

Want to add 60?
Need to create NEW bigger array and COPY everything! 😱
```

## 📖 Formal Definition

> **A Linked List is a linear data structure where elements (nodes) are stored at non-contiguous memory locations, connected together using pointers.**

---

## 🧩 Anatomy of a Node

Each element in a Linked List is called a **NODE**.

```
┌─────────────────────────────────────────────────────────┐
│                      A NODE                             │
├─────────────────────────────────────────────────────────┤
│                                                         │
│    ┌─────────────────────┬─────────────────────┐        │
│    │        DATA         │        NEXT         │        │
│    │                     │      (pointer)      │        │
│    │    Actual value     │   Address of next   │        │
│    │    we want to       │       node          │        │
│    │       store         │                     │        │
│    └─────────────────────┴─────────────────────┘        │
│                                                         │
│    Think of it as:                                      │
│    📦 A box with your item + 📍 directions to next box  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 🎬 How Linked List Looks in Memory

```
LINKED LIST (Non-contiguous Memory):

HEAD
  │
  ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ DATA │ NEXT  │     │ DATA │ NEXT  │     │ DATA │ NEXT  │
│  10  │  ─────────> │  20  │  ─────────> │  30  │ null  │
└──────────────┘     └──────────────┘     └──────────────┘
   Address: 1000        Address: 2048        Address: 1536

Notice: Addresses are NOT sequential!
Node 1 is at 1000
Node 2 is at 2048 (not 1004!)
Node 3 is at 1536 (not 2052!)

They're scattered in memory but CONNECTED by pointers!
```

## 🔷 Type 1: Singly Linked List

**Each node points to the NEXT node only. One-way street!**

```
┌─────────────────────────────────────────────────────────────────────┐
│                      SINGLY LINKED LIST                             │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   HEAD                                                              │
│    │                                                                │
│    ▼                                                                │
│  ┌────┬────┐   ┌────┬────┐   ┌────┬────┐   ┌────┬────┐              │
│  │ 10 │  ──┼──>│ 20 │  ──┼──>│ 30 │  ──┼──>│ 40 │null│              │
│  └────┴────┘   └────┴────┘   └────┴────┘   └────┴────┘              │
│                                                                     │
│   Direction: ──────────────────────────────────────>                │
│               Can only go FORWARD                                   │
│                                                                     │
│   Analogy: A treasure hunt where each clue                          │
│            leads to the NEXT clue only!                             │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 💻 Implementation in JavaScript:

```javascript
// Node class for Singly Linked List
class Node {
  constructor(data) {
    this.data = data; // The actual value
    this.next = null; // Pointer to next node
  }
}

// Singly Linked List class
class SinglyLinkedList {
  constructor() {
    this.head = null; // Start of the list
    this.size = 0; // Track number of nodes
  }

  // Check if list is empty
  isEmpty() {
    return this.size === 0;
  }

  // Get the size
  getSize() {
    return this.size;
  }
}

// Creating nodes manually (for understanding)
let node1 = new Node(10);
let node2 = new Node(20);
let node3 = new Node(30);

// Connecting them
node1.next = node2; // 10 → 20
node2.next = node3; // 20 → 30
// node3.next is already null (end of list)

console.log(node1.data); // 10
console.log(node1.next.data); // 20
console.log(node1.next.next.data); // 30
```

## 🔷 Type 2: Doubly Linked List

**Each node points to BOTH next AND previous. Two-way street!**

```
┌─────────────────────────────────────────────────────────────────────┐
│                      DOUBLY LINKED LIST                             │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│     HEAD                                                TAIL        │
│       │                                                   │         │
│       ▼                                                   ▼         │
│  ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐    │
│  │   null   │     │          │     │          │     │          │    │
│  │    ↑     │     │    ↑     │     │    ↑     │     │    ↑     │    │
│  │   prev   │     │   prev   │     │   prev   │     │   prev   │    │
│  │ ┌──────┐ │     │ ┌──────┐ │     │ ┌──────┐ │     │ ┌──────┐ │    │
│  │ │  10  │ │<───>│ │  20  │ │<───>│ │  30  │ │<───>│ │  40  │ │    │
│  │ └──────┘ │     │ └──────┘ │     │ └──────┘ │     │ └──────┘ │    │
│  │   next   │     │   next   │     │   next   │     │   next   │    │
│  │    ↓     │     │    ↓     │     │    ↓     │     │    ↓     │    │
│  │          │     │          │     │          │     │   null   │    │
│  └──────────┘     └──────────┘     └──────────┘     └──────────┘    │
│                                                                     │
│   Direction: <──────────────────────────────────────────>           │
│                    Can go FORWARD and BACKWARD!                     │
│                                                                     │
│   Analogy: Metro train - you can see both                           │
│            the station you came from AND the next one!              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 💻 Implementation in JavaScript:

```javascript
// Node class for Doubly Linked List
class DoublyNode {
  constructor(data) {
    this.data = data;
    this.next = null; // Pointer to next node
    this.prev = null; // Pointer to previous node
  }
}

// Doubly Linked List class
class DoublyLinkedList {
  constructor() {
    this.head = null; // First node
    this.tail = null; // Last node
    this.size = 0;
  }

  isEmpty() {
    return this.size === 0;
  }
}

// Creating and connecting doubly linked nodes
let dNode1 = new DoublyNode(10);
let dNode2 = new DoublyNode(20);
let dNode3 = new DoublyNode(30);

// Forward connections
dNode1.next = dNode2;
dNode2.next = dNode3;

// Backward connections
dNode2.prev = dNode1;
dNode3.prev = dNode2;

// Now we can traverse both ways!
console.log(dNode2.next.data); // 30 (forward)
console.log(dNode2.prev.data); // 10 (backward)
```

## 🔷 Type 3: Circular Singly Linked List

**Last node points back to the first node. It's a circle!**

```
┌─────────────────────────────────────────────────────────────────────┐
│                   CIRCULAR SINGLY LINKED LIST                       │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│                         ┌──────────────────────────────────┐        │
│                         │                                  │        │
│                         ▼                                  │        │
│   HEAD               ┌────┬────┐   ┌────┬────┐   ┌────┬────┤        │
│    └────────────────>│ 10 │  ──┼──>│ 20 │  ──┼──>│ 30 │  ──┘        │
│                      └────┴────┘   └────┴────┘   └────┴────┘        │
│                                                                     │
│                                                                     │
│   Visual as a circle:                                               │
│                                                                     │
│                    ┌──── 10 <────┐                                  │
│                    │             │                                  │
│                    ▼             │                                  │
│                   20             │                                  │
│                    │             │                                  │
│                    ▼             │                                  │
│                   30 ────────────┘                                  │
│                                                                     │
│   Analogy: Ferris wheel - keeps going round and round!              │
│            Player turns in a board game                             │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 💻 Implementation in JavaScript:

```javascript
// Circular Singly Linked List
class CircularLinkedList {
  constructor() {
    this.head = null;
    this.tail = null;
    this.size = 0;
  }

  // Add to end (makes it circular)
  append(data) {
    const newNode = new Node(data);

    if (!this.head) {
      this.head = newNode;
      this.tail = newNode;
      newNode.next = this.head; // Points to itself!
    } else {
      this.tail.next = newNode;
      this.tail = newNode;
      this.tail.next = this.head; // Complete the circle!
    }

    this.size++;
  }

  // Print (be careful - infinite loop possible!)
  print() {
    if (!this.head) return;

    let current = this.head;
    let result = [];

    do {
      result.push(current.data);
      current = current.next;
    } while (current !== this.head); // Stop when back to head

    console.log(result.join(" → ") + " → (back to head)");
  }
}

let circular = new CircularLinkedList();
circular.append(10);
circular.append(20);
circular.append(30);
circular.print(); // 10 → 20 → 30 → (back to head)
```

# Chapter 5: All Basic Operations

## 📌 Operation 1: INSERTION

### 🔹 Insert at Beginning (Prepend) ⏱️ O(1)

```
BEFORE:
HEAD
 │
 ▼
┌────┬──┐   ┌────┬──┐   ┌────┬──┐
│ 20 │──┼──>│ 30 │──┼──>│ 40 │──┼──> null
└────┴──┘   └────┴──┘   └────┴──┘

INSERT 10 at beginning:

Step 1: Create new node with data 10
        ┌────┬──┐
        │ 10 │  │  (next is null initially)
        └────┴──┘

Step 2: Point new node's next to current head
        ┌────┬──┐
        │ 10 │──┼──┐
        └────┴──┘  │
                   ▼
HEAD ─────────────>┌────┬──┐   ┌────┬──┐   ┌────┬──┐
                   │ 20 │──┼──>│ 30 │──┼──>│ 40 │──┼──> null
                   └────┴──┘   └────┴──┘   └────┴──┘

Step 3: Move HEAD to new node
HEAD
 │
 ▼
┌────┬──┐   ┌────┬──┐   ┌────┬──┐   ┌────┬──┐
│ 10 │──┼──>│ 20 │──┼──>│ 30 │──┼──>│ 40 │──┼──> null
└────┴──┘   └────┴──┘   └────┴──┘   └────┴──┘

DONE! Only 2 operations - doesn't matter if list has 1 or 1 million nodes!
```

```javascript
    // Insert at the beginning - O(1)
    prepend(data) {
        const newNode = new Node(data);

        if (this.isEmpty()) {
            this.head = newNode;
        } else {
            newNode.next = this.head;  // New node points to old head
            this.head = newNode;       // Head now points to new node
        }

        this.size++;
    }
```

### 🔹 Insert at End (Append) ⏱️ O(n)

```
BEFORE:
HEAD
 │
 ▼
┌────┬──┐   ┌────┬──┐   ┌────┬──┐
│ 10 │──┼──>│ 20 │──┼──>│ 30 │──┼──> null
└────┴──┘   └────┴──┘   └────┴──┘

INSERT 40 at end:

Step 1: Create new node
        ┌────┬──┐
        │ 40 │──┼──> null
        └────┴──┘

Step 2: Traverse to find the LAST node

HEAD
 │
 ▼
┌────┬──┐   ┌────┬──┐   ┌────┬──┐
│ 10 │──┼──>│ 20 │──┼──>│ 30 │──┼──> null  ← This is the last node!
└────┴──┘   └────┴──┘   └────┴──┘            (next is null)
  ↑           ↑           ↑
  │           │           │
Start      Continue     STOP! (next is null)

Step 3: Point last node to new node
HEAD
 │
 ▼
┌────┬──┐   ┌────┬──┐   ┌────┬──┐   ┌────┬──┐
│ 10 │──┼──>│ 20 │──┼──>│ 30 │──┼──>│ 40 │──┼──> null
└────┴──┘   └────┴──┘   └────┴──┘   └────┴──┘

DONE!
```

```javascript
    // Insert at the end - O(n)
    append(data) {
        const newNode = new Node(data);

        if (this.isEmpty()) {
            this.head = newNode;
        } else {
            // Traverse to the last node
            let current = this.head;

            while (current.next !== null) {
                current = current.next;
            }

            // current is now the last node
            current.next = newNode;
        }

        this.size++;
    }
```

### 🔹 Insert at Specific Position ⏱️ O(n)

```
BEFORE: 10 → 20 → 40 → null
INSERT 30 at index 2:

INDEX:   0     1     2
        10 → 20 → 40 → null
                  ↑
             Insert 30 here

Step 1: Create new node 30

Step 2: Traverse to node at index (position - 1) = 1

        10 → 20 → 40 → null
              ↑
           Stop here (index 1)
           This is the "previous" node

Step 3: Adjust pointers

        newNode.next = previous.next  (30 → 40)
        previous.next = newNode       (20 → 30)

AFTER: 10 → 20 → 30 → 40 → null
```

```javascript
    // Insert at specific index - O(n)
    insertAt(data, index) {
        // Validate index
        if (index < 0 || index > this.size) {
            console.log("Invalid index");
            return;
        }

        // If inserting at beginning
        if (index === 0) {
            this.prepend(data);
            return;
        }

        const newNode = new Node(data);
        let current = this.head;

        // Traverse to the node BEFORE the insertion point
        for (let i = 0; i < index - 1; i++) {
            current = current.next;
        }

        // Insert the new node
        newNode.next = current.next;
        current.next = newNode;

        this.size++;
    }
```

### 🔹 Delete at Specific Position ⏱️ O(n)

```javascript
    // Delete at specific index - O(n)
    deleteAt(index) {
        // Validate index
        if (index < 0 || index >= this.size) {
            console.log("Invalid index");
            return null;
        }

        // If deleting first node
        if (index === 0) {
            return this.deleteFirst();

        // Traverse to node BEFORE the one to delete
        let current = this.head;

        for (let i = 0; i < index - 1; i++) {
            current = current.next;
        }

        // current.next is the node to delete
        const removedData = current.next.data;
        current.next = current.next.next;
        this.size--;

        return removedData;
    }
```

```javascript
    // Reverse the linked list - O(n)
    reverse() {
        let prev = null;
        let current = this.head;
        let next = null;

        while (current !== null) {
            // Save next
            next = current.next;

            // Reverse the link
            current.next = prev;

            // Move prev and current forward
            prev = current;
            current = next;
        }

        // prev is now the new head
        this.head = prev;
    }
```

## 📌 Operation 6: Finding Middle Element

### 🔹 Two-Pointer Technique (Slow & Fast) ⏱️ O(n)

```javascript
        let fast = this.head;
```

# Chapter 6: Complete Doubly Linked List

```javascript
// ═══════════════════════════════════════════════════════════════
//              DOUBLY LINKED LIST IMPLEMENTATION
// ═══════════════════════════════════════════════════════════════

class DoublyNode {
  constructor(data) {
    this.data = data;
    this.next = null;
    this.prev = null;
  }
}

class DoublyLinkedList {
  constructor() {
    this.head = null;
    this.tail = null;
    this.size = 0;
  }

  isEmpty() {
    return this.size === 0;
  }

  // Insert at beginning - O(1)
  prepend(data) {
    const newNode = new DoublyNode(data);

    if (this.isEmpty()) {
      this.head = newNode;
      this.tail = newNode;
    } else {
      newNode.next = this.head;
      this.head.prev = newNode;
      this.head = newNode;
    }

    this.size++;
  }

  // Insert at end - O(1) ← Better than singly linked!
  append(data) {
    const newNode = new DoublyNode(data);

    if (this.isEmpty()) {
      this.head = newNode;
      this.tail = newNode;
    } else {
      newNode.prev = this.tail;
      this.tail.next = newNode;
      this.tail = newNode;
    }

    this.size++;
  }

  // Delete from beginning - O(1)
  deleteFirst() {
    if (this.isEmpty()) return null;

    const removedData = this.head.data;

    if (this.size === 1) {
      this.head = null;
      this.tail = null;
    } else {
      this.head = this.head.next;
      this.head.prev = null;
    }

    this.size--;
    return removedData;
  }

  // Delete from end - O(1) ← Better than singly linked!
  deleteLast() {
    if (this.isEmpty()) return null;

    const removedData = this.tail.data;

    if (this.size === 1) {
      this.head = null;
      this.tail = null;
    } else {
      this.tail = this.tail.prev;
      this.tail.next = null;
    }

    this.size--;
    return removedData;
  }

  // Print forward
  printForward() {
    let current = this.head;
    let result = [];

    while (current) {
      result.push(current.data);
      current = current.next;
    }

    console.log("null ← " + result.join(" ⟷ ") + " → null");
  }

  // Print backward - O(n)
  printBackward() {
    let current = this.tail;
    let result = [];

    while (current) {
      result.push(current.data);
      current = current.prev;
    }

    console.log("null ← " + result.join(" ⟷ ") + " → null");
  }
}

// Usage
const dll = new DoublyLinkedList();
dll.append(10);
dll.append(20);
dll.append(30);
dll.prepend(5);

dll.printForward(); // null ← 5 ⟷ 10 ⟷ 20 ⟷ 30 → null
dll.printBackward(); // null ← 30 ⟷ 20 ⟷ 10 ⟷ 5 → null
```

```javascript
  let newHead = reverseListRecursive(head.next);
```

```javascript
function mergeTwoLists(l1, l2) {
  // Dummy node to simplify edge cases
  let dummy = new Node(0);
  let current = dummy;

  while (l1 !== null && l2 !== null) {
    if (l1.data <= l2.data) {
      current.next = l1;
      l1 = l1.next;
    } else {
      current.next = l2;
      l2 = l2.next;
    }
    current = current.next;
  }

  // Attach remaining nodes
  current.next = l1 !== null ? l1 : l2;

  return dummy.next;
}
```

**Visualization:**

```
l1: 1 → 3 → 5
l2: 2 → 4 → 6

Step 1: 1 < 2, take 1 → result: 1
Step 2: 3 > 2, take 2 → result: 1 → 2
Step 3: 3 < 4, take 3 → result: 1 → 2 → 3
Step 4: 5 > 4, take 4 → result: 1 → 2 → 3 → 4
Step 5: 5 < 6, take 5 → result: 1 → 2 → 3 → 4 → 5
Step 6: l1 is null, attach l2 → result: 1 → 2 → 3 → 4 → 5 → 6
```

## 🎯 Problem 4: Find Nth Node from End

```javascript
function nthFromEnd(head, n) {
  let fast = head;
  let slow = head;

  // Move fast n steps ahead
  for (let i = 0; i < n; i++) {
    if (fast === null) return null; // n is larger than list
    fast = fast.next;
  }

  // Move both until fast reaches end
  while (fast !== null) {
    slow = slow.next;
    fast = fast.next;
  }

  return slow; // slow is at nth from end
}
```

```javascript
function removeDuplicates(head) {
  if (head === null) return null;

  let current = head;

  while (current.next !== null) {
    if (current.data === current.next.data) {
      // Skip the duplicate
      current.next = current.next.next;
    } else {
      current = current.next;
    }
  }

  return head;
}
```

```javascript
function isPalindrome(head) {
  if (head === null || head.next === null) return true;

  // Find middle
  let slow = head;
  let fast = head;

  while (fast.next !== null && fast.next.next !== null) {
    slow = slow.next;
    fast = fast.next.next;
  }

  // Reverse second half
  let secondHalf = reverseList(slow.next);

  // Compare first and second half
  let p1 = head;
  let p2 = secondHalf;

  while (p2 !== null) {
    if (p1.data !== p2.data) return false;
    p1 = p1.next;
    p2 = p2.next;
  }

  return true;
}
```

## 🎯 Problem 7: Find Intersection of Two Lists

```javascript
function getIntersectionNode(headA, headB) {
  if (headA === null || headB === null) return null;

  let pA = headA;
  let pB = headB;

  // When pA reaches end, redirect to headB
  // When pB reaches end, redirect to headA
  // They'll meet at intersection or both become null

  while (pA !== pB) {
    pA = pA === null ? headB : pA.next;
    pB = pB === null ? headA : pB.next;
  }

  return pA;
}
```

**Why this works:**

```
List A: a1 → a2 → c1 → c2 → c3
List B: b1 → b2 → b3 → c1 → c2 → c3

Length of A before intersection: 2
Length of B before intersection: 3

pA travels: a1→a2→c1→c2→c3→b1→b2→b3→c1
pB travels: b1→b2→b3→c1→c2→c3→a1→a2→c1

Both travel same distance (5 + 3 = 8) and meet at c1! ✅
```
